       PolyC: I64 ReadDigit(U8 *p) { ... }
             I64 AccDigit(I64 acc, U8 *p) { ... }
       B0-shaped multi-block byte + comparison + digit + accumulator fixture.
       Currently COMPILES and passes llvm-as + opt --passes=verify
       for both ReadDigit and AccDigit. AccDigit exercises the
       Option-W / mem2reg production path (multi-block I64 mutable
       result state with conditional store/load).
