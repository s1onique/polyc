# ACT-POLYC-SELFHOST-DRIVER-REQUIRED-ROUTE-CORRECTION03, C4 ROUND 4, F6.

# THE DEFECT. The runtime archive declared the runtime producer as an
# ORDER-ONLY prerequisite:
#
#     $(TEST_PREFIX_LIBTOS): ... | $(RUNTIME_PRODUCER_PATH)
#
# An order-only prerequisite says "must EXIST", not "must be NEWER". The
# producer CONTENT was therefore never re-examined by make, and the rule
# body SHA-256 check never ran unless the rule happened to run for another
# reason. A producer whose bytes were corrupted left the cached archive
# accepted as up to date.
#
# THE RED -- the producer is corrupted and make accepts the cached archive.
#
