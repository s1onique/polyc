WHAT IS UNDER REVIEW.

The C4 ROUND 6 review produced FIVE P1 findings (R6-01 .. R6-05) and ONE
P2 disposition (the `src/tests/run.HC` failure-propagation defect). The
ROUND 7 subject claims to have repaired the five P1 findings.

    R6-01  THE ARGUMENT VECTOR'S CONSTRUCTION. The caller converted the
           scan's indices into the built vector's coordinates with
           `index + 1`, which DESTROYED THE MISSING SENTINEL: an absent
           source and an absent output option both became the valid
           index 0. The runner therefore DROPPED the caller's request.
           The capacity was a fixed `nsupplied + 3`.

    R6-02  THE STDOUT EMISSION. The compiler's own `-o-` spelling was
           rewritten into `-o <generated-basename>`, so the compiler
           wrote an assembly FILE where the caller had asked for the
           standard output. The captured stdout was empty, an unintended
           artifact appeared, and the capture record nevertheless claimed
           `OUTPUT_MODE STDOUT`.

    R6-03  THE COMPILED SNAPSHOT'S IDENTITY. The event identity bound the
           ORIGINAL source's digest, and the comparator read
           `SOURCE_SHA256`. The staged snapshot -- the file the compiler
           actually consumed -- was never validated.

    R6-04  THE POSITIVE PROBES. Several positive controls passed without
           proving successful compiler behaviour. Most importantly,
           `R6ExecMode()` set `nargs = 2`, which EXCLUDED the `-o-`
           option from the argument vector; the child exited 1 and the
           control passed because it asserted only that no expected
           harness reason token appeared. Other controls read source
           bytes instead of proving artifact absence, tested the wrong
           symlink location, or compared recorded digest strings
           without hashing the staged file.

    R6-05  THE ADVERSE SUITE'S FIXTURE CONSTRUCTION. The recipe declared
           `good/source.HC` and constructed an argv containing the
           RELATIVE `good/off/source.HC`. The corrected source-binding
           validation returned `HARNESS_SOURCE_CONTRADICTED`, and the
           target exited 2 before executing any of its intended adverse
           cases.
