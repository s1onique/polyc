Mechanically: when both compilers produce byte-identical
object code on a source, the linked compiler binary's
output is identical. Object parity is end-to-end
conservation evidence of the highest cheap observable.
It does NOT logically imply that the intermediate
lex/paser/AST states are identical; different intermediate
states can, in principle, converge to identical machine
code. This pillar therefore claims ONLY object-emission
parity. Direct cursor-binding equivalence is established
by pillar B (see cursor-direct-witness.txt).
