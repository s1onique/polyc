=================================================

§7 B1 source self-compilation proof.

------------------------------------------------------------
Source
------------------------------------------------------------

```text
tools/bootstrap/bootstrap02-ident.HC
```

This is the single PolyC source file that constitutes
the B1 component. It is written in HolyC / PolyC (not
in C), it implements `BootstrapScanIdent`, and it is
linked into the stage1 compiler `hcc-bootstrap02`.

------------------------------------------------------------
Fresh compilation (current tree)
------------------------------------------------------------

```text
$ ./build/hcc              --install-dir ./build/test-prefix \
    -c tools/bootstrap/bootstrap02-ident.HC \
    -o /tmp/c4-ident-A.o
$ ./build/hcc-bootstrap02  --install-dir ./build/test-prefix \
    -c tools/bootstrap/bootstrap02-ident.HC \
    -o /tmp/c4-ident-B.o

$ shasum -a 256 /tmp/c4-ident-A.o /tmp/c4-ident-B.o
a1b620c076e81d898f953889f2b9db97f0bf8f6228af3b4a10644e2e78cd854f  /tmp/c4-ident-A.o
a1b620c076e81d898f953889f2b9db97f0bf8f6228af3b4a10644e2e78cd854f  /tmp/c4-ident-B.o
```

The two objects are byte-identical (SHA-256 equal).

The current tree reproduces the exact canonical B1

available proof that:

  - the stage1 build path is deterministic;
  - the B1 component code is byte-stable;
  - no regression has entered the bootstrap seam since
    the C3 forward-fix.
