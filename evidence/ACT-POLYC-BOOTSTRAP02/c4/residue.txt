P2.3  Makefile runner can false-green child compilation
-------------------------------------------------------

```text
CLASS             = TEST_INFRASTRUCTURE / GOVERNANCE
PRODUCTION_IMPACT = NONE
BLOCKS_B1_CLOSE   = NO
BLOCKS_B2_OPEN    = NO
```

The `unit-test` / `jit-unit-test` recipes chain
compilation subcommands with `&&`, which does NOT
propagate child compilation failures back to make's
return code. Therefore a runner that appears to make
EXIT 0 may still have produced no executable. This is
classified as test-infrastructure defect, NOT a B1
compiler defect. Recorded for a future bounded
correction ACT (out of B1 scope).
