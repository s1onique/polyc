ACT-POLYC-BOOTSTRAP02 — C1 — ABI witness
========================================

AC05: Cross-language C↔PolyC ABI witness passes.

Goal
----

Prove that the proposed B1 ABI can be lowered by stage0 hcc
and called from a host C harness with byte-exact semantics.
The witness uses the exact B1 ABI signature:

    public I64 BootstrapScanIdent(
        U8  *src,        // caller-owned, read-only
        I64  src_len,
        I64  start,
        I64 *out_end);

ABI witness probe
-----------------

The ABI probe is in tools/quality/bootstrap02-abi-probe.HC:

    public I64 BootstrapAbiProbe3(U8 *src, I64 src_len,
                                   I64 start, I64 *out_end)
    {
      I64 i = start;
      I64 n = src_len;
      while (i < n) {
        U8 c = src[i];
        if (c < '0') break;
        if (c > '9') break;
        i = i + 1;
      }
      *out_end = i;
      return 1;
    }

This is intentionally simpler than BootstrapScanIdent (it
counts ASCII digits) but exercises the same ABI signature:
U8 *, I64, I64, I64 *out_end.

Host C harness
--------------

The harness is in tools/quality/bootstrap02-abi-host.c:

    extern long long BootstrapAbiProbe3(unsigned char *src,
                                         long long src_len,
                                         long long start,
                                         long long *out_end);

    int main(void) {
      unsigned char buf[] = "12345abc";
      long long len = 8;
      long long start = 0;
      long long end = -1;
      long long ret = BootstrapAbiProbe3(buf, len, start, &end);
      printf("ret=%lld end=%lld (expected ret=1 end=5)\n", ret, end);
      printf("STATUS=%s\n", (ret == 1 && end == 5) ? "PASS" : "FAIL");
      return (ret == 1 && end == 5) ? 0 : 1;
    }
