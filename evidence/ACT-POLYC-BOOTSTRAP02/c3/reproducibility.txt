must be behaviorally equivalent. Binary-hash equality
is desirable but not mandatory; behavioral equivalence
IS mandatory.

Section D — Behavioral equivalence (binding)
------------------------------------------------------------

Both Build A and Build B produced the same corpus
result counts:

  STAGE0_PASS_STAGE1_PASS = 175
  STAGE0_FAIL_STAGE1_FAIL =   6
  STAGE0_FAIL_STAGE1_PASS =   0
  STAGE0_PASS_STAGE1_FAIL =   0

The full corpus matrix TSV for Build A is at
corpus-matrix-buildA.tsv; for Build B at
corpus-matrix-buildB.tsv. The two matrices are
byte-identical:

  $ diff -q corpus-matrix-buildA.tsv corpus-matrix-buildB.tsv
  $ echo $?
  0

Additionally, on Build B:
  - make bootstrap02-test        -> BOOTSTRAP02_DIFFERENTIAL=PASS 15/15
  - make bootstrap02-cursor-test -> BOOTSTRAP02_CURSOR_DIFFERENTIAL=PASS 6/6
  - make bootstrap02-lexer-seam-test
        -> BOOTSTRAP02_LEXER_SEAM_DOWNSTREAM=PASS (6/6 cases byte-identical)
        -> BOOTSTRAP02_LEXER_SEAM_RESIDUE=NONE

(Because Build A's binaries are byte-identical to
Build B's, and Build B's tests pass, Build A's tests
also pass — equivalent by transitivity of byte
equality through input equivalence.)
