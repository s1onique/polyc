ACT-POLYC-BOOTSTRAP01 — C1 — frozen fixture matrix
====================================================

All fixtures are byte-exact. Whitespace is `' '` (0x20)
unless otherwise noted. T09 is the only multi-whitespace
fixture.

T13 detail
----------

The driver passes `&src[3]` and `src_len - 3` to
`BootstrapLex`. The lexer is expected to use offsets
relative to the slice's start. For input `"xx foo"`,
the slice is `"foo"` and tokens should report
`(IDENT, 0, 3)` against the slice, with the EOF at
`(start=3, len=0)`.

T14 detail
----------

T14 is a 60-character identifier: `abcdefghijklmnopqrstu
vwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ012345` (exactly 60 ASCII
bytes). It exercises the inner identifier loop's
back-edge without overflowing any internal buffer.

Per-fixture expected outputs are recorded in
`sibling-file oracle-baseline.txt`. The C oracle at
`tools/quality/bootstrap01-lexer-oracle.c` MUST emit
exactly those outputs for these inputs.
