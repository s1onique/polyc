Aggregate layout for BootstrapToken
-----------------------------------

B0 needs to write three I64 fields per token: kind, start,
len. The substrate chain proves struct field store via
`ACT-POLYC-LLVM-OPTION-W-OUT-PARAM01`. The C2 IMPL uses
the equivalent of:

    typedef struct { I64 kind; I64 start; I64 len; } BootstrapToken;

in a `class` declaration under PolyC source. This is
struct construction by literal field assignment, which is
the same shape Option-W exercised.

Note on native backend ABI for structs containing only
I64s: AArch64 / x86-64 pass them by value in registers or
on stack with alignment 8. The B0 fixture exercises only
single-struct reads/writes; no aggregate-by-value return
or sret path is needed.

No new ABI change is required.
