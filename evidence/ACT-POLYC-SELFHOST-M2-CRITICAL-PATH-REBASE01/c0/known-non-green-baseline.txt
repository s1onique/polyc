THE FIVE NEW COMPILER DEFECTS DISCOVERED BY THE PREDECESSOR
--------------------------------------------------------------------------
These are carried forward as KNOWN OPEN RESIDUE (not fixed by this ACT,
which authorizes no production change). They are re-examined against
the selected source closure at C1.
  RES-01  a global variable WITH AN INITIALISER makes the compiler
          emit the entry point with argc=0, so a PolyC program cannot
          read its own arguments.
  RES-02  a duplicate extern "c" declaration of a library function
          whose return type differs from the header's produces a
          BROKEN call that segfaults with no diagnostic.
  RES-03  three-dimensional arrays are not supported.
  RES-04  the ternary operator is not supported.
