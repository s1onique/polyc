# THE INDEPENDENT FIXTURE VERIFICATION.
#
# THE REQUIREMENT (ACT section 5 item 5)
#
#   "Add a standalone source-independent fixture verifier in PolyC
#    which independently derives the legal enums and semantic expected
#    values from the G0 object witness and source.  Fail closed on
#    deleted, duplicated, unknown, malformed, out-of-range or
#    misclassified rows.  The verifier may not derive expectations from
#    the new PolyC implementation or read the fixture generator's
#    expected column as oracle."
#
# ---------------------------------------------------------------------------
# THE VERIFIER
# ---------------------------------------------------------------------------
#
#   build/parser-slice07-fixture-integrity
#     <- tools/quality/parser-slice07-fixture-integrity.HC  (PolyC)
#
# The verifier is a SEPARATE program from the producer.  It does NOT
# share the producer's counting path:
#
#   * it READS THE LIVE SOURCE BYTES of src/ast.h and src/parser.c;
#   * it PARSES the enum values out of the ast.h TEXT;
#   * it tests every fixture record against the fixture-id PATTERN
#     directly (four decimal digits, zero padded);
#   * a record that does not match is a NON-DATA record and is accepted
#     only when it is a recognized comment or a recognized metadata
#     row; an unknown record is a FAILURE;
#   * it recomputes every row's expected value from the SOURCE-BOUND
#     constants and compares it against the fixture's expected column.
#
# It does NOT read the new PolyC implementation, and it does NOT take
# the fixture's expected column as its oracle: the expected value is
# RECOMPUTED from src/ast.h and compared.
#
# ---------------------------------------------------------------------------
# THE MEASURED RESULT ON THE PRISTINE FIXTURE
# ---------------------------------------------------------------------------
#
# COMMAND=./build/parser-slice07-fixture-integrity \
#           evidence/ACT-POLYC-SELFHOST-PARSER-SLICE07/c1/fixture.tsv \
#           src/ast.h src/parser.c
#
# FIXTURE_INTEGRITY_PATH=evidence/ACT-POLYC-SELFHOST-PARSER-SLICE07/c1/fixture.tsv

# ---------------------------------------------------------------------------
# THE ADVERSE CONTROLS: THE VERIFIER IS NOT VACUOUS
# ---------------------------------------------------------------------------
#
# Each control MUTATES the fixture or the live source, re-runs the SAME
# verifier, and records the detector that fired.  The pristine fixture
# is restored after each control.
#
# S7-FC-01 -- DELETE one fixture row.
#
# COMMAND=grep -v '^0001	' <fixture> > /tmp/s07-fc01.tsv
# COMMAND=./build/parser-slice07-fixture-integrity /tmp/s07-fc01.tsv src/ast.h src/parser.c
#   FIXTURE_INTEGRITY_MISSING_ID=1
#   FIXTURE_INTEGRITY_MISSING_IDS=1
#   FIXTURE_INTEGRITY_STATUS=FAIL
#
# DETECTOR=MISSING EXACT FIXTURE ID.  SENSITIVE.
#
# S7-FC-02 -- DUPLICATE one fixture id.
#
# COMMAND=(head -1 <fixture>; grep '^0001	' <fixture>; tail -n +2 <fixture>) > /tmp/s07-fc02.tsv
# COMMAND=./build/parser-slice07-fixture-integrity /tmp/s07-fc02.tsv src/ast.h src/parser.c
#   FIXTURE_INTEGRITY_DUPLICATE_ID=1
#   FIXTURE_INTEGRITY_DUPLICATE_IDS=1
#   FIXTURE_INTEGRITY_STATUS=FAIL
#
# DETECTOR=DUPLICATE ID.  SENSITIVE.
#
# S7-FC-03 -- ADD an unknown fixture id.
#
# COMMAND=(cat <fixture>; echo '9999	...') > /tmp/s07-fc03.tsv
# COMMAND=./build/parser-slice07-fixture-integrity /tmp/s07-fc03.tsv src/ast.h src/parser.c
#   FIXTURE_INTEGRITY_DUPLICATE_IDS=0

# DETECTOR=the unknown id EXPANDS the expected id set, so the real ids
# are reported MISSING and the unknown id is NOT reported as a
# duplicate.  The detector distinguishes "unknown" from "duplicate",
# exactly as the control requires.  SENSITIVE.
#
# S7-FC-04 -- FLIP one expected outcome.
