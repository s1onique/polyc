# THE INDEPENDENT RECOMPUTATION OF EVERY SEMANTIC PREDICATE.
#
# The ACT requires "a separate PolyC program [that] recomputes all
# semantic predicates from source-bound facts/G0 fixture/provenance,
# without consuming C2 PASS rows as its oracle."
#
# The recomputer is
#   tools/quality/parser-slice07-fixture-integrity.HC
# which:
#
#   * READS the LIVE SOURCE BYTES of src/ast.h and src/parser.c;
#   * PARSES AST_DECL and AST_GVAR out of the ast.h TEXT;
#   * RE-DERIVES the expected value of every fixture row from those
#     source-bound constants;
#   * COMPARES the recomputed value against the fixture's column.
#
# It does NOT read the new PolyC implementation, and it does NOT
# consume the C2 PASS rows.  Its output is INDEPENDENT of the C2
# evidence by construction.
#
COMMAND=./build/parser-slice07-fixture-integrity \
#         evidence/ACT-POLYC-SELFHOST-PARSER-SLICE07/c1/fixture.tsv \
#         src/ast.h src/parser.c
#
