# THE THREE PROPERTIES OF THIS WITNESS

# 1. THE POLYC CALL IS PRESENT AND IS LOAD-BEARING.
#    The `bl` at 0x3a68 is a real branch to the component, and the

#    COMMAND=objdump -r build/CMakeFiles/hcc.dir/parser.c.o | grep BootstrapCompound

#    COMMAND=objdump -d ... | sed -n '/<_parseCompoundStatementInternal>:/,/^$/p' \
#             | grep -cE 'cmp.*#256'

#    COMMAND=... | grep -oE 'cmp\s+w[0-9]+, #[0-9]+' | sort -u

#    The `b.ne` at 0x3a4c branches OVER the `ldr` at 0x3a50, so the
#    declvar load is NOT reached unless stmt->kind == AST_DECL.  The
#    `mov w1, #0` at 0x3a5c is the non-declaration projection value.
#    This is the SAME structure the C1 read-count harness exercised.
