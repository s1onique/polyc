# The detector fired for its INTENDED reason, and it reported the
# EXACT affected semantic input: (263, 256).  The LEGACY oracle still

# The pristine subject was restored by construction: the mutant is a

# N01_SENSITIVE=YES
# N01_REPORTED_THE_EXACT_INPUT_ID=YES

# ---------------------------------------------------------------------------
# CONTROL 2: THE LEGACY C DECISION IS STILL ACTIVE BESIDE THE
#             DELEGATION  (the S7-PR-04 shape)
# ---------------------------------------------------------------------------
#
# The C2 disassembly witness is the detector: the production function
# is searched for a comparison against 256 (AST_GVAR).
#
# COMMAND=objdump -d build/CMakeFiles/hcc.dir/parser.c.o \
#           | sed -n '/<_parseCompoundStatementInternal>:/,/^$/p' \
#           | grep -cE 'cmp.*#256'
#   0
#
# If the legacy `if (stmt_kind == AST_DECL && declvar_kind == AST_GVAR)
# return 0;` were still ACTIVE beside the delegation, this count would
# be 1 and the detector would FIRE.  The count is 0, so the legacy
# semantic decision is RETIRED and the C side does not make the
# append/skip decision at all.
#
# The complementary check is that the ONE AST_DECL comparison that
# remains is the AUTHORIZED PROJECTION GUARD, and it is distinguished
# from a semantic decision by its POSITION and by its CONTROL FLOW: it
# guards a dereference (`b.ne` over the `ldr` of stmt->declvar) and it
# does NOT feed the SKIP/APPEND branch.  The SKIP/APPEND branch is fed
# ONLY by the `cbz w0` that tests the PolyC component's return value.
#
# S7_PR_04_DETECTOR=THE FUNCTION-SCOPED AST_GVAR COMPARISON COUNT
# S7_PR_04_COUNT=0
# LEGACY_C_DECISION_STILL_ACTIVE=NO
# C_SIDE_COMPUTES_THE_DECISION=NO
#

# ---------------------------------------------------------------------------
# CONTROL 4: THE PROJECTION GUARD IS NOT A SECOND DECISION
# ---------------------------------------------------------------------------
#
# The distinguishing witness is the ONE remaining AST_DECL comparison
# and its role.  The full list of comparison immediates in the
# production function is:
#
#   cmp w0, #263     <- the AUTHORIZED projection guard
#   cmp w8, #11      <- pre-existing, unrelated
#   cmp w8, #768     <- pre-existing, unrelated
#
# There is NO comparison against 256, so there is no C-side semantic
# decision.  A second decision would have required the AST_GVAR
# comparison, and it is absent.
#
# The C0 pre-state, for the comparison, carried BOTH:
#   cmp w8, #263 and cmp w8, #256

# The detector is the CALL-SITE RELOCATION, not the symbol's presence:

# COMMAND=objdump -r build/CMakeFiles/hcc.dir/parser.c.o | grep BootstrapCompound
