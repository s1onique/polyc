#   src/CMakeLists.txt:1117
#     message(FATAL_ERROR "Tooling runtime host is macOS-only in this
#       build.  Linux support is ACT-POLYC-TOOLING-LINUX-PORT01.")
# That is a DELIBERATE, PRE-EXISTING, HONEST gate (it is designed to
# fail rather than silently produce a forged-Apple libtos). It is NOT
# introduced by this ACT and it is NOT in this ACT's scope.
#
# What that means for the Linux row, precisely:
#   * The OBJECT VERIFICATION layer -- which is what this ACT hardens --
#     is fully exercised natively on Linux, because it depends ONLY on
#     cmake, nm and the object file. It has no dependency on hcc or on
#     libtos (measured: the verifier source contains no reference to
#     either).
#   * The VALID PRODUCTION LINK is exercised natively on Linux with a
#     REAL ELF object and a REAL ELF link, and the linked program RUNS
#     and returns the correct result.
#   * The FULL PolyC compiler build on Linux remains blocked by the
#     pre-existing project gate above. That is recorded here honestly
#     rather than papered over.
