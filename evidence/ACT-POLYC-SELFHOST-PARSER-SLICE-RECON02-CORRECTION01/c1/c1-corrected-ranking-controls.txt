# The nine mandatory anti-bias controls (ACT SECT_8.3), RE-RUN against
# the FULL hard-eligibility predicate (SECT_8.1).  The predecessor ran
# CONTROL 5 and CONTROL 6 over a BROADER set (the state-boundary filter)
# and therefore reported a selection change that the fully eligible set
# does not exhibit.  This file records the corrected controls.
#
# The ranker (build/slice-recon02-rank/rank.sh) and the independent
# eligibility re-derivation (build/slice-recon02-rank/elig.sh) are
# disposable diagnostics in the IGNORED build directory.  They are NOT
# tracked tools.
#
# =========================================================================
# SCOPE OF THE PROOF -- READ THIS BEFORE THE CONTROL RESULTS
# =========================================================================
# There are TWO distinct predicates, and this ACT keeps them separate:
#
#   (P) ELIGIBILITY  -- the 13-clause hard-eligibility conjunction
#       (ACT SECT_8.1).  Decided by elig.sh, which re-derives the
#       conjunction INDEPENDENTLY from the predecessor's committed C1
#       artifacts (inventory, dependency map, call sites, observable
#       projections).  elig.sh does NOT consume an `eligible` flag.
#
#   (R) RANKING -- the lexicographic order over (R0..R6) of the rows that
#       ELIGIBILITY admitted.  Decided by rank.sh, which drops every row
#       whose `eligible` column is not YES before sorting.
#
# rank.sh CONSUMES an `eligible` column.  It does not compute
# eligibility.  Therefore:
#
#   * A row whose `eligible` column was written BY HAND into the rank
#     input proves (R) ONLY.  It does NOT prove (P) for that row.
#   * A row whose `eligible` column was DERIVED from elig.sh's output
#     proves (P) AND (R), end to end.
#
# The controls below are stated in BOTH forms:
#
#   FORM A  -- the REAL set, produced by elig.sh over the predecessor's
#              committed C1 artifacts.  Proves (P) for every admitted row
#              and (R) over the admitted set.  This is the authoritative
#              form.
#   FORM B  -- the FALSIFIABLE form, in which a second candidate is added.
#              The second candidate is put through elig.sh as a COMPLETE
#              candidate (all four C1 artifacts), so its eligibility is
#              ADMITTED BY THE ELIGIBILITY CHECKER, not asserted.
#
# The synthetic control candidate is named CAND-101 and is NOT a real
# candidate: it exists only to make the ranking claim observable.  It is
# proven INELIGIBLE-free (i.e. ELIGIBLE) by the checker itself, and the
# checker's NEGATIVE behaviour is demonstrated too, so that "the checker
# admits it" is a meaningful statement rather than a rubber stamp.
#
# The ranker self-check below establishes that rank.sh still reproduces
# the historical RECON01 winner, so the ranking behaviour exercised here
# is the same behaviour the predecessor relied on.
