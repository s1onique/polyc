## Symptom

Running any regression / conservation harness that emits
live transcripts (in particular, `make llvm-spike-test`)
DIRTIES four files inside historical, already-closed
ACT evidence trees:

  evidence/llvm-core04-resume01/c2/red-multi_def/red-multi_def.live.stderr
  evidence/llvm-core04-resume01/c2/red-multi_def/red-multi_def.live.summary
  evidence/llvm-memory01/spike/red-6-live-transcripts/red-1B.emit.stderr
  evidence/llvm-memory01/spike/red-6-live-transcripts/red-2.emit.stderr

This violates the conservation invariant:

  run every regression/conservation harness
  then: git status --porcelain
  must NOT contain anything under:
    evidence/llvm-core04-resume01/
    evidence/llvm-memory01/
    any other closed ACT evidence tree

The contamination is reproducible (see diff.txt: the same
four files appear every run) and the drift is a counter
that should not be re-emitted during ordinary regression:

  before: CAPABILITY_COUNTERS supported=2 ... =0
  after : CAPABILITY_COUNTERS supported=7 ... =0

## Contamination producer (identified)

scripts/quality/llvm-spike-test.sh
  line 42 : EVID=${LLVM_SPIKE_EVID_OVERRIDE:-"$REPO_ROOT/evidence/llvm-memory01/spike"}
  line 285: EVID_CORR=${LLVM_SPIKE_EVID_CORR_OVERRIDE:-"$REPO_ROOT/evidence/llvm-memory01/spike/red-6-live-transcripts"}

when `LLVM_SPIKE_EVID_*` is not overridden.

scripts/quality/llvm-memory01-*.sh also write into
closed-ACT paths by default.

target.

phase with its own evidence artefact.
