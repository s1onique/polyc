DIAGNOSIS (carried from C1):

  RED_PRIVATE_FNS_STALE_STATE (HALT_JIT_PRIVATE_STATE_LEAK):
    HccJit's private_fns Map is populated by every chunk's static
    functions, consulted at finalize to skip the corresponding labels
    from symbols / host_symbols, but NEVER cleared between chunks.
    chunk_fns IS cleared per chunk; private_fns is not. This violates
    the contract in src/jit-common.h:45-50 ("Reset per chunk").

  Consequence:
    chunk1 compiles static Foo  -> private_fns += "Foo"
    chunk2 compiles public Foo  -> finalize skips registration
    chunk3's reference to Foo   -> JIT: unresolved symbol '_Foo'

  "%d\n", Foo();' | hcc -repl --install-dir=...
