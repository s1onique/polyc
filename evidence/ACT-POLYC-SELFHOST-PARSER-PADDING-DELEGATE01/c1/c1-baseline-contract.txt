## Halt semantics

Any deviation from a frozen baseline identity triggers a halt:

* `HALT_LEXER07_FORWARD_BASELINE_REGRESSION` if NEW_LEXER07_*
  tokens are non-zero
* `HALT_LEXER_CONSERVATION` if any LEXER0*_CONSERVATION != PASS
* `HALT_PARSER_LAYOUT_REGRESSION` if PARSER_LAYOUT_NEW_FAILURES > 0
* `HALT_PARSER_REGRESSION` if PARSER_NEW_FAILURES > 0
