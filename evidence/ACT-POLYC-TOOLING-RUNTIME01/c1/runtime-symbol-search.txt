------------------------------------------------------------
Method
------------------------------------------------------------

  1. Static grep over the PolyC standard library
     (src/holyc-lib/*.HC, src/holyc-lib/tos.HH) for each
     required primitive name.
  2. Static grep over the compiler C source for the same
     primitives (proof that they are real, not stubs).
  3. Where the symbol lives in libc only, confirm that
     an extern "c" binding exists so a PolyC program can
     actually call it.

Tooling used:

  ripgrep (rg) / grep -n across src/

------------------------------------------------------------
Summary
------------------------------------------------------------

Of the required primitives, the following are
presently MISSING and must be implemented in C2:

  1. A high-level direct-argv spawn that captures
     stdout/stderr separately and reports exit code
     without shell parsing.
  2. Race-safe temporary-file creation (mkstemp
     binding or equivalent).
  3. A multi-byte substring-search helper (strstr
     wrapper) for text assertions.

Everything else either exists already or can be
built from existing primitives.
