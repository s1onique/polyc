=== RECONCILIATION WITH CORRECTION03 cmake-install.log ===

The CORRECTION03 install log captured earlier shows the same six
ar/ranlib/xcrun-cache warnings but cmake --install still exited 0.
This is because:
  - hcc_lib_result is intentionally NOT fatal (RESULT_VARIABLE check)
  - ar r, ranlib, cc -dynamiclib, ln -sf all returned 0
  - the xcrun "couldn't create cache file" messages are stderr noise
    that does NOT affect the actual archive content or return code
  - the entire install step is a single execute_process() per
    sub-command, each guarded by COMMAND_ERROR_IS_FATAL ANY

The CORRECTION02 install step had `&&` literal-argv (which would
have produced ar: &&: No such file or directory as an actual
non-zero exit, which CORRECTION03's COMMAND_ERROR_IS_FATAL ANY
would now catch).  CORRECTION03 does NOT have that defect, and
the install step is now both mechanically correct and observably
green against a fresh prefix.
