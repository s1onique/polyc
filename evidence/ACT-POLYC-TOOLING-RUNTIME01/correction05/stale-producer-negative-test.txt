=== ROOT CAUSE ===

The CORRECTION03 install step had:
  file(MAKE_DIRECTORY ${LIBTOS_BUILD_DIR})  # create-once at configure
  install(CODE "execute_process(...hcc -lib...)")  # produce
  install(CODE "if(NOT EXISTS all.o) FATAL_ERROR")  # guard

`file(MAKE_DIRECTORY)` is idempotent and runs at configure
time, not at install time. So on a re-install, the build dir
(including any prior all.o) persists. The hcc invocation
fails (in this test, sabotage; in production, possibly broken
toolchain or transient I/O). The `if(NOT EXISTS all.o)`
guard sees the stale file from the prior run and install
proceeds using yesterday's object.

The right invariant is: **before each install run, the
producer's output area must be empty.** Achieved via
`file(REMOVE ...)` as the first install(CODE) step.
