  R1. ACT-POLYC-PARSER-TERNARY-HANG01
      The HolyC parser hangs (does not fail-fast) on unsupported
      `?:` ternary expressions in non-trivial programs. Bisected
      to `U8 *x = cond ? a : b;` inside a function body. Was a
      side-finding during CORRECTION01 stress testing; not
      exercised by the tooling runtime.

  R2. ACT-POLYC-TOOLING-LINUX-PORT01
      The Tooling runtime's EINTR helpers currently use macOS-
      only `__error()` via a small C shim (errno_shim.c). On
      glibc the equivalent is `__errno_location()`. Until this
      ACT opens, libtos compiles only on macOS. The hermetic
      build/test-prefix/ subtree contains a macOS libtos.a.

  R3. ARG[3] OVERRUN IN SUPERSEDED FIXTURE
      evidence/.../correction01/deadlock_probe.HC has a `U8 *args[3]`
      with 4 assigned slots (out-of-bounds). The file is now
      marked SUPERSEDED — not authoritative. The C-side pair
      (deadlock_probe.c + dl_check.HC) is the authoritative
      fixture for CORRECTION01.

  R4. RC=127 SPAWN/EXEC AMBIGUITY
      Missing executable produces rc=127 (execv fails; child
      `_exit(127)`). Legitimate child `_exit(127)` produces
      rc=127 too. AC22 now reads as documented contract, with
      P2 followup: introduce an explicit spawn-failed indicator
      (separate return channel, or rc=-2) so callers can
      disambiguate.
