int astUnaryOpFromToken(s64 op, AstUnOp *_result) {
    switch (op) {
        case TK_PRE_PLUS_PLUS:   *_result = AST_UN_OP_PRE_INC; break;
        case TK_PRE_MINUS_MINUS: *_result = AST_UN_OP_PRE_DEC; break;
        case TK_PLUS_PLUS:       *_result = AST_UN_OP_POST_INC; break;
        case TK_MINUS_MINUS:     *_result = AST_UN_OP_POST_DEC; break;
        case '+':                *_result = AST_UN_OP_PLUS;    break;
        case '-':                *_result = AST_UN_OP_MINUS;   break;
        case '~':                *_result = AST_UN_OP_BIT_NOT; break;
        case '!':                *_result = AST_UN_OP_LOG_NOT; break;
        case '&':                *_result = AST_UN_OP_ADDR_OF; break;
        case '*':                *_result = AST_UN_OP_DEREF;   break;
        default:
            return 0;
    }
    return 1;
}

THE STATE AND SIDE-EFFECT BOUNDARY
-------------------------------
  GLOBAL_STATE_READS=0
    The body reads only its scalar parameter `op` and the switch
    cases.  It reads no global, no file, no environment.
  HOST_AST_GRAPH_MUTATIONS=0
    The only write is through the caller's output pointer.  No Ast* is
    created, mutated or freed.
  CALLBACK_DEPENDENCIES=0
    The body calls nothing.
  NONLOCAL_RECOVERY_DEPENDENCIES=0
    The body contains no cctrlRaiseException, no loggerPanic, no
    longjmp, no setjmp interaction.
  HOST_POINTER_IDENTITY_REQUIRED=NO
    The output pointer's IDENTITY is irrelevant: the function writes
    THROUGH it, it does not compare it, store it, or return it.
  ALLOCATION=0
    Nothing is allocated.

  The C output-pointer write is ABI STORAGE, not AST graph
  authority.  The PolyC component therefore NEVER RECEIVES that
  pointer: the PolyC ABI is a pure scalar in, scalar out.
