READING THE DISASSEMBLY
----------------------
  The function is a JUMP TABLE over the ASCII range 0x21..0x7d, plus
  four explicit comparisons against the lexer token constants
  0x305 (TK_PLUS_PLUS), 0x306 (TK_MINUS_MINUS), 0x330 (TK_PRE_PLUS_PLUS)
  and 0x331 (TK_PRE_MINUS_MINUS).

  The enum results stored through the output pointer are:
    w8 = 0x6  (AST_UN_OP_LOG_NOT)   <- the '!' case
    w8 = 0x8  (AST_UN_OP_ADDR_OF)   <- the '&' case
    w8 = 0x9  (AST_UN_OP_DEREF)     <- the '*' case
    w8 = 0x4  (AST_UN_OP_PLUS)      <- the '+' case
    w8 = 0x5  (AST_UN_OP_MINUS)     <- the '-' case
    w8 = 0x1  (AST_UN_OP_POST_DEC)  <- TK_MINUS_MINUS (0x306)
    w8 = 0x2  (AST_UN_OP_PRE_DEC)   <- TK_PRE_MINUS_MINUS (0x331)
    w8 = 0x0  (AST_UN_OP_POST_INC)  <- TK_PLUS_PLUS (0x305)
    w8 = 0x3  (AST_UN_OP_PRE_INC)   <- TK_PRE_PLUS_PLUS (0x330)
    w8 = 0x7  (AST_UN_OP_BIT_NOT)   <- the '~' case

  The store is `str w8, [x1]` -- the output-pointer write -- followed by
  `mov w0, #0x1` (return 1).  The default path at 0x844 returns with w0 = 0
  and does NOT store, which is the "output unchanged on failure" property
  visible in the machine code itself.

  IMPORTANT: the enum VALUES above are read off the COMPILED machine code
  of the ENTRY tree, not inferred from the enum names.  C1 rederives them
  independently by compiling the live src/ast.h.
