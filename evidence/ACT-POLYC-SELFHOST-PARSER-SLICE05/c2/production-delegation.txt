THE PRODUCTION DELEGATION
=======================

THE PRODUCTION ast.c.o REFERENCES THE POLYC SYMBOL
-----------------------------------------------
COMMAND=nm build/CMakeFiles/hcc.dir/ast.c.o | grep -i "unaryopfromtoken\|BootstrapAst"
                 U _BootstrapAstBinOpFromToken
                 U _BootstrapAstUnaryOpFromToken
00000000000006d4 T _astUnaryOpFromToken

  UNARY_PRODUCTION_OBJECT_REFERENCES_POLYC=YES
    The production ast.c object carries an UNDEFINED reference
    to _BootstrapAstUnaryOpFromToken.  The C wrapper symbol
    _astUnaryOpFromToken remains for ABI compatibility.

THE PRODUCTION ADAPTER (machine code)
-------------------------------

  READING THE DISASSEMBLY
  ----------------------
    bl    -> the CALL to the PolyC component
    tbnz  -> the TEST of the -1 failure sentinel
    str   -> the CONDITIONAL write through the output pointer
    mov w0,#1 / mov w0,#0 -> the SUCCESS/FAILURE conversion

  THERE IS NO JUMP TABLE AND NO SWITCH.  The legacy mapping is
  NOT PRESENT in the production object.  This is the machine-level
  proof that the LEGACY_SWITCH_EXECUTED=NO.

  LEGACY_SWITCH_EXECUTED=NO
