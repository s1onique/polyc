ROOT CAUSE (measured, and PRE-EXISTING)
  The range check reads the CLOSE commit's trailers with
    git log -1 --format='%(trailers:key=ACT,...)'
  and Git 2.54.0's TRAILER PARSER REJECTS THE ENTIRE TRAILER BLOCK when
  it contains a key with an UNDERSCORE in it. Measured:

    $ printf 'x\n\nACT: A\nACT-Phase: CLOSE\n' | git interpret-trailers --parse
    ACT: A
    ACT-Phase: CLOSE
    -> PARSES

    $ printf 'x\n\nACT: A\nACT-Phase: CLOSE\nHALT_CLASS: G\n' | git interpret-trailers --parse
    -> EMPTY (the whole block is dropped)

    $ for k in HALT_CLASS BLOCKS_NEXT HALT_X HALTCLASS halt_class; do
          printf "x\n\nACT: A\n$k: G\n" | git interpret-trailers --parse | tr '\n' ' '
          echo "  <- key=$k"; done
      (nothing)  <- key=HALT_CLASS
      (nothing)  <- key=BLOCKS_NEXT
      (nothing)  <- key=HALT_X
      ACT: A HALTCLASS: G   <- key=HALTCLASS
      (nothing)  <- key=halt_class

    => Every trailer key containing an underscore makes Git drop the
       whole trailer block, so %(trailers) yields nothing at all.

  The CLOSE commit legitimately carries HALT_CLASS and BLOCKS_NEXT
  because ACT section 42 REQUIRES them for a HALT_* verdict.
