WHY THIS IS A BOOTSTRAP-GRAPH DEFECT (not a runtime defect)
  The producer build/hcc-bootstrap04 is itself produced by the chain
  bootstrap04-stage3 -> bootstrap03-stage2 -> bootstrap02-stage1 ->
  bootstrap02-component-build -> test-prefix-install -> cmake configure ->
  HCC_BOOTSTRAP. The configure-time gate therefore forbids the very chain
  that is supposed to produce the gate's input. The check must MOVE from
  global configure time to the point where the runtime producer is actually
  required (the install step).
