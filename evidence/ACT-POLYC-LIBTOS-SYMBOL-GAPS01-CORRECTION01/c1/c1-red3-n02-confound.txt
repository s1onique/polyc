RED-3: N02 negative control is confounded; the canonical, properly-
       isolated N02 produces a clean _SpawnAndCapture-only failure.

Test design (per ACT §4):
  Procedure A (predecessor's broken procedure):
    Re-derive the corrupted archive by re-running
    `cc -c errno_shim.c` and `ar r libtos-corrupted.a errno_shim.o`
    in a working directory where errno_shim.o does not exist.
    Expected (per the predecessor's evidence):
      ar: errno_shim.o: No such file or directory
    Then link the consumer; expect failure citing both
    _SpawnAndCapture AND _Errno.

  Procedure B (correct isolation):
    1. Extract pristine archive members into a fresh dir.
    2. Use llvm-objcopy --localize-symbol=_SpawnAndCapture all.o.
       Verify: nm all.o shows T -> t for _SpawnAndCapture.
    3. Rebuild archive with ar rcs, including:
       - the modified all.o
       - the ORIGINAL errno_shim.o (NOT recompiled)
    4. Link consumer. Expect failure citing ONLY _SpawnAndCapture.
