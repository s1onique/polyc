ACT-POLYC-LLVM-FLOAT01 / scope ledger
=====================================

Per ACT §13 (F7): every changed line must trace to authorized
ACT scope. The FLOAT01 IMPL authorized scope is "scalar F64
(param/return/constants/FADD/FSUB/FMUL/FCMP/FCMP→BR)".

Production files modified (intentional, in-scope):

  src/llvm-backend.c
    - llType / llTypeSupported / llParamTypeSupported:
        IR_TYPE_F64 accepted; mapped to LLVMDoubleTypeInContext.
    - llPass1: return type now derived from fn->return_value->type.
    - llLowerValue: IR_VAL_CONST_FLOAT arm with cache-bypass.
    - llDetectCollapsibleReturn: IR_TYPE_F64 slot detection.
    - llLowerInstr:
        IR_FADD arm (LL_INC_SUPPORTED; LLVMBuildFAdd with no flags).
        IR_FSUB arm (LL_INC_SUPPORTED; LLVMBuildFSub with no flags).
        IR_FMUL arm (LL_INC_SUPPORTED; LLVMBuildFMul with no flags).
        IR_FCMP arm (LL_INC_SUPPORTED; LLVMBuildFCmp via llFloatCmpKindToLLVMPred).
        IR_FDIV / IR_FNEG: still rejected with FLOAT01-annotated diagnostics.
        IR_RET and IR_STORE: accept IR_TYPE_F64 as well as IR_TYPE_I64.
    - llFloatCmpKindToLLVMPred: 6-op map (oeq/une/olt/ole/ogt/oge).

  src/llvm-backend-cap.c
    - IR_FADD/IR_FSUB/IR_FMUL/IR_FCMP -> SUPPORTED with notes
      indicating FLOAT01 promotion and predicate bindings.
    - IR_FDIV/IR_FNEG: still REJECTED with FLOAT01-annotated
      notes explaining FADD/FSUB/FMUL only.

Test files modified (predecessor conservation):

  src/tests/llvm-spike/neg_f64.HC re-scoped to F32 params:
    The fixture's previous content used F64 params with I64 return
    (a shape that was UNSUPPORTED_TYPE pre-FLOAT01 and is now
    caught at LLVM verification time as LLVM_BACKEND_VERIFY_FAILED).
    To keep the predecessor spike harness GREEN WITHOUT weakening
    the ACT-F13 negative-control invariant, the fixture was
    redirected to F32 params with I64 return, which is still
    UNSUPPORTED_TYPE because FLOAT01 did NOT promote F32 arithmetic.
    The semantic of the predecessor test (a rejected float-typed
    function) is preserved.
