# (EXACT_COMMIT_COUNT_AT_CLOSE=5 and POST_C4_COMMIT_COUNT=0).
#
# Mechanism: BEFORE the C4 commit exists, capture the current HEAD
# SHA as PRE_C4_FROZEN_TIP_SHA.  After the C4 commit exists,
# observe via:
#
#   AC38:  git rev-list --count <ENTRY>..HEAD  → 5
#          (compare against PRE_C4_FROZEN_TIP_SHA:
#           git rev-list --count <ENTRY>..<PRE_C4_FROZEN_TIP_SHA>  → 4)
#
#   AC40:  git rev-list --count <PRE_C4_FROZEN_TIP_SHA>..HEAD  → 1
#          (no commits exist AFTER the frozen tip)
#          and
#          git merge-base --is-ancestor <PRE_C4_FROZEN_TIP_SHA> HEAD  → 0
#          (the frozen tip is reachable by parent edge)
#
# This replaces the predecessor's non-load-bearing mechanisms:
#   - `git rev-list --count 1274f36..HEAD = 4` (a pre-C4 prediction)
#   - `git rev-list --count HEAD..HEAD = 0` (a tautology)
#
# with two external witnesses:
#   (a) a frozen SHA captured BEFORE C4 exists;
#   (b) post-C4 observations of the committed range relative to
#       that frozen SHA.
