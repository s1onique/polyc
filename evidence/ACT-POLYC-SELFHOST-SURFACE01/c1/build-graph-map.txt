The same PolyC source
(`tools/bootstrap/bootstrap02-ident.HC`) is recompiled at
each stage; the resulting objects are byte-identical
because the B1 component is small and deterministic.

Per-generation wiring mechanics
------------------------------------------------------------

```text

  Makefile:
    bootstrap02-component-build
  src/CMakeLists.txt:
```

------------------------------------------------------------
What the generic surface must reconstruct
------------------------------------------------------------

```text
Given only:
  - SELF-HOST-COMPONENTS.tsv (component_id=identifier_scanner)
  - the registry row (source, symbol, consumer_seam,
    language, state, oracle, cursor_gate,
    production_seam_gate, introduced_by)
  - the existing compiler stages (./hcc,
    build/hcc-bootstrap02, build/hcc-bootstrap03,
    build/hcc-bootstrap04)
  - the existing oracle / harness / corpus / error scripts

The generic surface must be able to:
  1. resolve component source from registry;
  2. invoke the right producer compiler for the
     requested stage;
  3. emit the object to a deterministic, stage-qualified
     path under build/selfhost/stage<N>/<component_id>.o;
  4. verify the expected symbol is exported;
  5. invoke the component oracle, cursor gate, and
     production-seam gate registered for the component;
  6. record provenance (component_id, source_path,
     producer_stage, producer_binary, producer_binary_hash,
     output_path, output_hash, expected_symbol).

It must do this without re-deriving the bespoke wiring by
hand each time a new component is added.
```
