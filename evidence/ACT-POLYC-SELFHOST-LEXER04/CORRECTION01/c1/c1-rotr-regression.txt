==============================================================

Reproduction setup: two separate .HC files, each defining its own
static U32 ROTR helper, plus a public wrapper. Each TU is compiled
independently to a .o via hcc -c, then merged with ld -r.

Source files (committed in c1/c1-rotr-minimal-reproducer-tuA.HC etc.):
  tuA.HC: static U32 ROTR(...); public U32 A_ROTR(U32 x) { return ROTR(x,7); }
  tuB.HC: static U32 ROTR(...); public U32 B_ROTR(U32 x) { return ROTR(x,13); }

Result with fix:

    0000000000000000 (__TEXT,__text) non-external _ROTR
  tuB.o symbols:
    00000000000000b4 (__TEXT,__text) external _B_ROTR
    0000000000000000 (__TEXT,__text) non-external _ROTR

ld -r merge (relink two .o files into one, equivalent to what
cc does for separate-compilation archives):
  ld -r rc=0
  combined.o symbols:
    00000000000000b4 T _A_ROTR
    0000000000000194 T _B_ROTR

Conclusion:
  STATIC_HELPER_COMPILES=YES              (tuA.HC and tuB.HC each compile)
  STATIC_HELPER_LINKS=YES                 (ld -r merges without error)
  STATIC_HELPER_NOT_EXPORTED_AS_FORBIDDEN_GLOBAL=YES
                                          (_ROTR is non-external in each .o)
  ROTR_REPRO_BEFORE=FAIL                  (pre-fix error: Cannot redefine)
