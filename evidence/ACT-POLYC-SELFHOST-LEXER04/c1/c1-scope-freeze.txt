CHOSEN ABI (from src/lexer.c lexLink analysis):

  /* Read-only: the entire lexer token state and the active
   * lexer pointer. We pass the cursor position (l->ptr)
   * and the active TK_* lexeme's start/len. */
  I64 BootstrapLinkDirective(
      U8  *src,         /* current cursor position (start of next lexeme) */
      I64  src_len,     /* bounded length of the remaining source from src */
      I64  flags,       /* l->flags (CCF_*) */
      I64  cc_link_libs_addr,    /* (I64)&l->cc->link_libs  -- output collection pointer */
      I64  cc_shared_object_files_addr, /* (I64)&l->cc->shared_object_files */
      I64 *out_consumed,         /* bytes consumed by the directive */
      I64 *out_is_path,          /* 1 if quoted-path form, 0 if angle-name form */
      I64 *out_stored_len,       /* length of stored AoStr (matches the stored AoStr's aoStrGetLen) */
      I64 *out_error             /* 0 = none, 1 = missing_target, 2 = invalid_token, 3 = unterminated_angle, 4 = unterminated_quoted */
  );

  The function returns 0 on success (directive consumed) and
  emits a CCTRL_ERROR via lexRaise semantics on the failure paths.
  In stage1+ builds, lexRaise itself remains a C symbol exported
  from src/lexer.c; BootstrapLinkDirective calls into it via a
  wrapper for the lexRaise path.
