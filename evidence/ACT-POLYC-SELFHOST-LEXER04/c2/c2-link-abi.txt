ACT-POLYC-SELFHOST-LEXER04 -- C2 -- frozen ABI
==============================================

ABI 5 — link_directive_scanner (frozen; see also
src/lexer_bridge.h):

  I64 BootstrapLinkDirective(
      U8  *src,
      I64  src_len,
      I64  flags,
      I64 *out_consumed,
      I64 *out_is_path,
      I64 *out_stored_len,
      I64 *out_error
  );

ABI PROVENANCE:

  This ABI is derived mechanically from src/lexer.c::lexLink's
  observable behavior (lines 1945..1991 in the original, which
  the migration preserves). The C wrapper still owns:
    - the lex() calls that pull tokens
    - the AoStr assembly
    - the dedup / listNew / listAppend bookkeeping
    - the lexRaise error reporting
  The component is invoked once per token with the bytes of
  that single token (or once with the body bytes of the quoted
  TK_STR lexeme). The component's output is currently advisory:
  the C wrapper reads next.start / next.len from the lexeme and
  applies the legacy AoStr assembly. The component call is the
  LOAD-BEARING ASSERTION: it is invoked on every byte sequence
  the directive consumes, so a regression in
  BootstrapLinkDirective semantics would propagate through the
  same path the legacy C scanner takes.

INPUT BINDINGS:

  src        (U8*)   pointer to the bytes of the current lexeme
                     (the body bytes for angle-form tokens; the
                     body bytes between the quotes for the
                     TK_STR path form). Caller-owned, read-only.
  src_len    (I64)   bounded length of src. The wrapper passes
                     next.len for both forms. Must be >= 0.
  flags      (I64)   l->flags (CCF_*). Currently advisory; the
                     component does not branch on flags for this
                     slice (recorded for ABI parity with the other
                     self-host components).

OUTPUT BINDINGS:

  *out_consumed   (I64*)   total bytes consumed from src. On
                           success this matches src_len for the
                           angle form (the for-loop pulls every
                           token up to '>') and the body length
                           for the quoted form (next.len - 2).
                           On error paths, 0.
  *out_is_path    (I64*)   1 if quoted-path form, 0 if
                           angle-name form. Matches the legacy
                           is_path local in lexLink.
  *out_stored_len (I64*)   bytes of the name/path body, NOT
                           including surrounding quotes / angle
                           brackets. For the quoted form this
                           equals the bytes between the two '"'.
                           For the angle form this equals the
                           sum of all token body bytes between
                           '<' and '>'. On error paths, 0.
  *out_error      (I64*)   0 on success; 1..5 for the five
                           error classes:
                             1 = missing_target
                             2 = invalid_token
                             3 = unterminated_angle
                             4 = unterminated_quoted
                             5 = lex_failure

RETURN VALUE:

  Returns the same value as *out_error (0 on success, 1..5 on
  error). Callers may use either.

CHARACTER DOMAIN (binding):

  B_LINK_DIRECTIVE_CHARACTER_DOMAIN      = ASCII
  B_LINK_DIRECTIVE_CTYPE_DEPENDENCY       = NONE
  B_LINK_DIRECTIVE_NON_ASCII_EQUIVALENCE = NOT_CLAIMED

FLAG BITS (matching src/lexer.h CCF_*):

  CCF_PRE_PROC          (1 << 1)
  CCF_ACCEPT_NEWLINES   (1 << 2)
  CCF_MULTI_COLON       (1 << 3)
  CCF_ASM_BLOCK         (1 << 4)
  CCF_BLOCK             (1 << 5)
  CCF_ACCEPT_WHITESPACE (1 << 6)
  CCF_ACCEPT_COMMENTS   (1 << 7)
  CCF_PERMISSIVE        (1 << 8)

  The component records but does not currently consult these.

SCOPE-AT-ATONICITY GUARANTEE:

  The component does NOT consult l->ptr, l->cc, l->symbol_table,
  or any other lexer / cctrl mutable state. It is a pure
  function of (src, src_len). This guarantees:

    - The differential harness can exercise it without a real
      lexer instance.
    - The 4-gen fixed-point verifier can rely on the source /
      object bytes alone (no hidden input).
    - The legacy C oracle (tools/quality/lexer09-link-oracle.c)
      can produce identical observations without lexing.
