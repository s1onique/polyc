ACT-POLYC-SELFHOST-LEXER04 -- C3 -- stage seam (production code path)
=======================================================================

STAGE TOPOLOGY:

  The LEXER04 component (BootstrapLinkDirective) is compiled by
  4 separate compiler binaries, producing 4 distinct .o files.
  Each compiler binary includes the previous generations'
  bootstrapped self-host components, so G3 transitively depends
  on G2, G1, and G0. The fixed point is established when all
  4 .o files are byte-identical (see c3-byte-equality.txt).

  G0  ./hcc                         (legacy C runtime, no bootstrapped components)
  G1  ./hcc-bootstrap02            (Bootstrap02Ident + BootstrapClassifyOperator)
  G2  ./hcc-bootstrap03            (Bootstrap03Ident + BootstrapClassifyOperator + BootstrapScanScalarLiteral + BootstrapScanTrivia + BootstrapLinkDirective[stage1])
  G3  ./hcc-bootstrap04            (Bootstrap04Ident + BootstrapClassifyOperator + BootstrapScanScalarLiteral + BootstrapScanTrivia + BootstrapLinkDirective[stage2])

  Each stage binary is built with cmake + gcc (standard C compilation)
  and statically links the PolyC-compiled component object file
  from the previous stage. The component object file from the
  current stage is then consumed by the next stage's cmake build
  (cmake-time validation rejects mismatch).
