WHAT THIS REPRODUCTION ESTABLISHES
==================================

The F2 SAFETY defect (Makefile:977/982/985 in the
predecessor ACT C2 IMPL) is repaired by:

  1. Removing `COMPONENT=$(COMPONENT)` /
     `STAGE=$(STAGE)` interpolation from recipe command
     text in Makefile:983 and Makefile:988.
  2. Passing COMPONENT and STAGE as exported
     environment variables (single-quoted in the
     recipe to prevent Make from word-splitting).
  3. Validating COMPONENT against
     /^[A-Za-z0-9_]+$/ in
     tools/selfhost/selfhost-component.sh.
  4. Validating STAGE against /^(0|1|2)$/ in the same
     file.

The shell receives the values via the environment, so
even though Make still expands `$(COMPONENT)` inside
the single-quoted assignment string, the resulting
shell variable contains the literal value (not the
shell-evaluated value). The script then refuses any
value containing shell metacharacters, FAILING CLOSED.
