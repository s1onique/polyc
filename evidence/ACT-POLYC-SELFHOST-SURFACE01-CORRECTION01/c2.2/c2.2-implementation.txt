# C2.2 IMPL summary

## Goal
Replace the Python registry/control plane for self-host components with a
PolyC implementation that preserves the frozen registry, build, provenance,
testing, safety, and artifact-equivalence contracts. Delete the Python source
files and the substantive shell wrappers in the selfhost family.

## Implementation

### tools/selfhost/selfhost-component.HC (NEW, ~1390 LOC PolyC)
Pure PolyC control plane. Composed of:
- SHCParseRegistry / SHCRegistryFind  - TSV row parser + lookup
- SHCValidateComponent / SHCStage     - row validator (source-existence, alias,
                                        symbol-name, language, state, seam)
- SHCGenericOutPath                   - path of generic producer output, derived
                                        purely from the registry row
- SHCOpValidate                       - validate subcommand (cold registry check)
- SHCOpBuild                          - build subcommand (uses SpawnAndCapture
                                        to invoke the right producer directly,
                                        then nm-symbol-validation)
- SHCOpTest                           - test subcommand (delegates to the
                                        frozen Makefile via SpawnAndCapture)
- SHCSelfTest                         - 13-class frozen negative-control suite
                                        (N1..N12b, mirrors the Python oracle)

Key constraints honored:
- No system(), no popen(), no shell-concat. Every process exec is direct argv
  via SpawnAndCapture with absolute paths.
- Source-existence + alias checks run inside SHCOpValidate (predecessor parity:
  N4/N11 expected to FAIL on validate, PASS on validate-disable, FAIL on build).
- Production parser == selftest parser (no clone).
- /usr/bin/env is used only as a portable env-injector for N2/N12b sub-spawns;
  no eval, no sh -c.

### tools/selfhost/selfhost-component.sh (REWRITTEN, 40 LOC dispatch glue)
Validates args, rejects shell metacharacters in COMPONENT, then exec's the
PolyC binary. No registry or build logic.

### scripts/quality/selfhost-component-registry.sh (REWRITTEN, 27 LOC)
Validates args, then exec's `./build/selfhost-component validate`. No registry
or build logic.

### scripts/quality/selfhost-component-registry.py (DELETED, 252 LOC)
### scripts/quality/selfhost-component-registry-test.sh (DELETED, 197 LOC)
