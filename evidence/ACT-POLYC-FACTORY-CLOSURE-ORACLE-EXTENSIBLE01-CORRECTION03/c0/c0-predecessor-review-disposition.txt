=== P0-G1: C0 pre-existing-work authorization ===

The CORRECTION02 C0 ACT body itself admitted:

  Entry identity:
    git branch --show-current = main
    git rev-parse HEAD        = b9a43f854ad8f82dd4c95bfabf6f71490f91e616
    git status --short        = clean (modulo unstaged whitespace fixes
                                  to CORRECTION01 evidence files; those
                                  are committed in C2 of this ACT)

The phrase "modulo unstaged whitespace fixes" is a F15 self-
authorization admission: implementation work existed before
authorization. The actual chronology is:

    whitespace repair begins
        |
        v
    C0 AUTH (records repair work as authorized scope)
        |
        v
    C1 RED
        |
        v
    C2 commits already-existing repair

not the C0 -> C1 -> C2 RED-before-fix flow that the AGENTS.md
binding contract requires. The repair itself may be correct; its
authorization lineage is not.

The defect is recorded as additive evidence under this ACT.
CORRECTION02's C0 ACT body is immutable per F14; it is not
rewritten.
