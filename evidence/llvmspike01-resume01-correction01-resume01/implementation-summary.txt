The only added names are diagnostic codes:
    LLVM_BACKEND_UNSUPPORTED_SSA_LOCAL
    LLVM_BACKEND_INTERNAL_UNBOUND_VALUE

The local-binding mechanism is implemented by reusing the
existing `lc->values` map (per-function vector of LLVMValueRef)
that already carries constant/parameter/instruction-result
bindings. IR_STORE local, value simply calls llvmSet(lc->values,
local-id, llLowerI64Value(value)); no new container, no new
helper.

MEMORY_FALLBACK = NO
    The backend never does:
        SSA lookup failed -> allocate stack slot -> continue
    Instead it exits with LLVM_BACKEND_INTERNAL_UNBOUND_VALUE
    or LLVM_BACKEND_UNSUPPORTED_SSA_LOCAL.
