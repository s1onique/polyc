THE SUBJECT DOES NOT DEPEND ON THE PRODUCTION COMPILER
--------------------------------------------------------

The subject is compiled by the STAGE-0 compiler, exactly like the
parser-padding, control-flow-token and operator-precedence subjects, so
the component does not depend on the production compiler that it is
about to serve.  The bootstrap chain stays acyclic (see
implementation-scope.txt).

THE SUBJECT'S PURITY PROPERTIES (ACT SECTION 8.1)
--------------------------------------------------

  NO_HOST_AST_POINTERS=YES   the function takes and returns one I64
  NO_ALLOCATION=YES          the body has no allocation call
  NO_GLOBAL_STATE=YES        the body reads no global
  NO_CALLBACKS=YES           the body calls nothing
  NO_RECOVERY_DEPENDENCY=YES the body has no setjmp/longjmp
  PURE_DETERMINISTIC_MAPPING=YES

The body is nineteen `if (token_value == N) return M;` tests followed
by `return -1;`.  Every input in the I64 domain has a defined output.

THE SUBJECT'S SCOPE
-------------------

The subject implements ONLY the selected mapping.  It does not
implement the unary mapping, the precedence table, the padding
computation or the control-flow-token check.
