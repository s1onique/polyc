WHY IT IS INDEPENDENT
---------------------

The witness is tools/quality/parser-slice04-fixture-integrity.HC.  It
does NOT share the fixture producer's token-resolution code: it never
resolves a token value at all.  It answers a DIFFERENT question -- the
FIXTURE STRUCTURE and the ID SET -- using a DIFFERENT counting path.

  * The differential classifies rows with a CONTEXTUAL state machine.
  * The witness counts rows with a WHOLE-FILE BYTE SCAN that has NO
    state machine: every record is tested against the fixture-id
    PATTERN directly (a canonical id is a fixed-shape token: 'F' plus
    exactly three decimal digits), and a record that does not match is
    counted as a NON-FIXTURE record.

The two counts are then compared with the differential's own count.

THE BYPASS CLASS IS CLOSED
--------------------------

A record that does not match the canonical id pattern is acceptable
ONLY when it is a RECOGNIZED non-data record: a comment, or a
KEY=VALUE metadata row.  EVERY OTHER record is an UNKNOWN ROW and is
REJECTED.

That is the check that closes the bypass class that
ACT-POLYC-SELFHOST-PARSER-SLICE-RECON03 reproduced in a closed tool:
a row whose id does not match the canonical pattern (for example
"X001", or an INDENTED "  X002") must NOT be silently skipped.  The
NC-03 and NC-04 negative controls exercise exactly those two shapes,
and the witness rejects both.
