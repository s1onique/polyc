THE RESTORED COMPONENT IS A REBUILD, NOT A COPY
------------------------------------------------

The step-C component is built AGAIN from the pristine source, by the
SAME stage0 compiler, with the SAME command:

  build/host-stage0/hcc --install-dir=<prefix> \
      -c build/slice04-mut/ws/selfhost-parser-slice04.HC \
      -o build/slice04-mut/restored.o

and it hashes to the SAME sha as the step-A component:

  C_COMPONENT_SHA_EQUALS_A=YES

So the restoration is a REPRODUCIBLE BUILD of the pristine source, not
a copy of the earlier object.  The tracked subject was never mutated
in any of the three steps.
