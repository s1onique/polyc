THE GATE RAN AGAINST THE COMMITTED TREE
=======================================

The gate-push gate creates a temporary detached Git worktree at the
subject commit and runs the full local native gate INSIDE it.  The
caller's working tree is not used directly, so the gate's result
establishes the gate for the COMMITTED tree and not for an uncommitted
worktree.
