# RESIDUE_R2 -- the LEXER07 broad corpus cannot be run from the
# Makefile target on a stable tree.
#
# The canonical target `make lexer07-broad-corpus-4-stage` rebuilds
# the four stage compilers and then runs the corpus. Running the
# corpus WHILE those compilers are being rewritten yields a corrupted
# measurement (measured: FAIL_S0=181 and FAIL_S0=43 on two such runs,
# neither of which reproduced on a stable tree). The cause is that the
# hcc compiler writes its assembly to the FIXED path /tmp/holyc-asm.s
# (src/main.c:35).
#
# This ACT therefore executed the SAME PolyC tool with the SAME
# canonical corpus inventory directly, which the ACT permits. This is
# a REPRODUCIBILITY DEFECT in the target, not in the corpus contract.
#
# It is a P2 residue for a future ACT: the target should build the
# stage compilers FIRST and run the corpus in a separate step, so that
# the measurement can never observe a compiler mid-rewrite. This ACT
# does not repair it, because changing the target's build ordering is
# outside the authorized scope of a correction that is bounded to the
# two review findings.
