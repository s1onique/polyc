Boundary-assertion smoke check:
    The diagnostic at src/llvm-backend.c:610-637 is reached
    only if IR_CMP_BR is presented. No test fixture presents
    IR_CMP_BR (because no code path produces it in the LLVM
    dispatch). The assertion therefore does not fire during
    the existing test matrix. A direct probe that synthetically
    produces IR_CMP_BR for the LLVM backend is OUT OF SCOPE
    here; it would require test-only IR injection machinery
    that BOUNDARY03 does not author.

    The existing llvm-spike-test (12/0 PASS) confirms no
    regression. The boundary-assertion is a passive guard
    that will fire if a future refactor accidentally moves
    native preparation above the neutral boundary.
