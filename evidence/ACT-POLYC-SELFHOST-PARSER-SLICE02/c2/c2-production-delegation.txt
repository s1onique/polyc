# ========================================================================
# 5. NO SILENT C FALLBACK
# ========================================================================
# The build is FAIL-CLOSED.  A missing or symbol-less component is a
# hard configure error, never a silent legacy fallback:
#
#   src/cmake/VerifyControlFlowTokenObject.cmake
#     - the object must EXIST
#     - the object must be non-empty
#     - the object must export _BootstrapValidPostControlFlowToken
#     - a missing `nm` is a hard error, never a pass
#
# Observed: configuring WITHOUT a producer, and with the component
# object absent, produced this hard error and aborted the configure
# (CONFIGURE_RC=1):
#
#   CMake Error at CMakeLists.txt:397 (message):
#     ACT-POLYC-SELFHOST-PARSER-SLICE02: required self-host
#     control-flow-token component missing at
#     .../build/parser-control-flow-token-subject.o.
#     Build it first with stage0 hcc: ...
#
# When a producer IS configured (the production Makefile does configure
# one), the build graph SCHEDULES the component's production instead,
# and the fail-closed symbol verification
# (VerifyControlFlowTokenObject.cmake) runs as a build step:
#
#   -- ACT-POLYC-SELFHOST-PARSER-SLICE02: production hcc SCHEDULES
#      control-flow-token subject production: .../parser-control-flow-token-subject.o
#   -- ACT-POLYC-SELFHOST-PARSER-SLICE02: production hcc links
#      control-flow-token PolyC component: .../parser-control-flow-token-subject.o
#
COMMAND_7=rm -rf <fresh build dir> && cmake -S ./src -B <fresh build dir> \
             -DHCC_USE_SELFHOST_PARSER_CONTROL_FLOW_TOKEN=ON
COMMAND_7_RESULT=(hard FATAL_ERROR; the configure aborted)
COMMAND_7_CONFIGURE_EXIT_STATUS=1
COMMAND_7_CONFIGURE_ABORTED=YES
NO_SILENT_C_FALLBACK=YES
  Both branches are fail-closed: with a producer the component is
  produced AND its exported symbol is verified before the link; without a
  producer a missing component is a hard configure error.  There is no
  path on which the production build proceeds without the verified
  PolyC component.
