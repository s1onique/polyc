ACT-POLYC-SELFHOST-LEXER03-CORRECTION02 -- C3 EVIDENCE -- G3 determinism
========================================================================

Per ACT §11: compile the same source with the same compiler (G3)
twice into two separate fresh outputs. This distinguishes a true
cross-generation mismatch from same-compiler nondeterminism.

COMMAND (literal):
  rm -f build/lexer08-fixedpoint/trivia.g3a.o build/lexer08-fixedpoint/trivia.g3b.o
  ./build/hcc-bootstrap04 --install-dir=$(pwd)/build/test-prefix \
      -c tools/bootstrap/selfhost-lexer-trivia.HC \
      -o build/lexer08-fixedpoint/trivia.g3a.o
  ./build/hcc-bootstrap04 --install-dir=$(pwd)/build/test-prefix \
      -c tools/bootstrap/selfhost-lexer-trivia.HC \
      -o build/lexer08-fixedpoint/trivia.g3b.o
  cmp -s build/lexer08-fixedpoint/trivia.g3a.o \
          build/lexer08-fixedpoint/trivia.g3b.o
  shasum -a 256 build/lexer08-fixedpoint/trivia.g3a.o \
                   build/lexer08-fixedpoint/trivia.g3b.o
