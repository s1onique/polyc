==================================================================
SCOPE_RATIONALE (why this target is atomic)
==================================================================

  R-H (comment + whitespace) is a single bounded responsibility
  with one shared-state contract (cursor + lineno + line_start_ptr)
  and one ABI shape (4-in / 4-out with a kind selector).

  The Pass-B-style merge is justified because:
    (a) Both regions touch the SAME mutable state.
    (b) Both regions share the SAME peek-ahead budget (1 byte).
    (c) Both regions share the SAME end-of-trivia boundary semantics.
    (d) The recon assigned them a FINAL_SCORE = +200 (positive).
    (e) Migrating R-G alone leaves R-I in C, which creates an
        ABI mismatch (one PolyC region + one C region both
        touching l->lineno + l->line_start_ptr).

  The migration does NOT change parser / IR / codegen / ABI / LLVM
  semantics. It only changes the implementation language of one
  lexer responsibility, preserving bit-identical observable behavior
  via the legacy C path during migration and the differential oracle
  as the equivalence proof.
