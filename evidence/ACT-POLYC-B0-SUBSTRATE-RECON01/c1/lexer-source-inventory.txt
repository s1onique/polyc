C. Lexer dispatch (src/lexer.c:1129-1482)
--------------------------------------------------------------------

  lexCore() reads one byte and dispatches:

    case '\r': '\n'                   -> increment lineno, optionally
                                          emit TK_PUNCT for newline
                                          when CCF_ACCEPT_NEWLINES
    case '\t': ' '                    -> skip whitespace, optionally
                                          emit TK_PUNCT when
                                          CCF_ACCEPT_WHITESPACE
    case '\0'                         -> return 0 (TK_EOF)
    case '0'..'9'                     -> lexNumeric()
    case '"'                          -> lexString() (allocates buffer)
    case '\''                         -> lexCharConst()
    case '/'                          -> lexSkipCodeComment() if next
                                          byte is '/' or '*',
                                          else '/' or '/=' punct
    case '=': '<': '>': '+': '-': '!':
    case '&': '|': '*': '%': '^':     -> multi-char punct with
                                          bounded one-byte lookahead
    case '$': '@'                     -> TK_PUNCT iff CCF_ASM_BLOCK
    case '.'                          -> numeric if next is digit;
                                          '..' '.' '...' puncutator;
                                          '..' lone is error
    case '\\'                         -> TK_PUNCT '\\'
    case '#'                          -> preprocessor directive
                                          (lexPreProcDirective)
    case ':'                          -> '::' (CCF_MULTI_COLON) or ':'
    case '~' '(' ')' ',' ';' '[' ']' '{' '}'
                                      -> TK_PUNCT single char
    default:
      if isalpha(ch) || ch == '_'    -> lexIdentifier() then
                                          symbol_table keyword lookup

  lexIdentifier (line 873-885):

    while ch && (isalnum(ch) || ch == '_' || ch == '$') consume.
    first char is set by caller: isalpha() || '_'.

  lexSkipCodeComment (line 762-792):

    '/'  -> consume until '\n' or '\0'
    '*'  -> consume until '*' followed by '/' (no nesting).
           EOF in unterminated block comment is tolerated.

  lexString (line 890-993):

    Reads "..." with full C-style escape decoding into a
    lexer-arena-allocated buffer. Tracks embedded '\n' as lineno++.

  lexCharConst (line 997-...):

    Reads 'x' / '\n' / '\xHH' / multi-byte sequences up to 8 bytes,
    produces a U64 scalar value.

  lexNumeric (line 1076-...):

    Reads [0-9]+ with optional hex (0x/0X), optional 'f32'/'f64'
    suffix, '.', 'e'/'E' exponent. Produces TK_I64 or TK_F64.

D. B0-relevant subset (this recon's interest)
--------------------------------------------------------------------

  The lexer uses these primitive operations at runtime:

    - Read byte at cursor                  (lexNextChar; *l->ptr)
    - One-byte peek/conditional advance    (lexPeekMatch; src[c])
    - Two-byte lookahead (comment "*/", "==" prefix)
    - Mutate cursor as bytes are consumed  (l->ptr++ in helpers)
    - Compare byte to ASCII literal
    - Classify first char (isalpha, isalnum, isdigit, isxdigit)
    - Allocate strings via lexerArena
    - Track lineno, line_start_ptr
    - Look up identifier text in a keyword Map (lexCore:1469)

  No token-array aggregation. No heap-allocated Token objects.
  Each Lexeme is a value with start/len aliasing into the source.
