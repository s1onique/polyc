=== D11 POSIX /bin/sh portability (reviewer-requested RED) ===

Bug: scripts/quality/formal-dafny.sh started with
`#!/bin/sh` but used Bash-only `PIPESTATUS[0]` to
capture the exit status of the verify pipeline.
PIPESTATUS is a Bash array variable, not POSIX. On
systems where /bin/sh is dash (Debian/Ubuntu default,
Alpine, etc.) the script would either fail to parse
or fail the exit-status check non-portably.

Fix (reviewer-prescribed, keep POSIX):
  set +e
  "$DAFNY" verify --warn-redundant-assumptions \
       --warn-contradictory-assumptions \
       "$DFY" >"$RV" 2>&1
  VRC=$?
  set -e
  cat "$RV"
  [ "$VRC" -eq 0 ] || { echo FATAL: ...; exit 1; }

After the fix, no Bash-only constructs remain.

bash-as-sh (Apple platform shell history), which is

This witness captures both runs as separate
executables, not as variants of the same /bin/sh.
