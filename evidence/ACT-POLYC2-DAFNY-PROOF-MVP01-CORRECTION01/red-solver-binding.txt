=== D15 explicit solver binding (reviewer-requested RED) ===

Pre-D15 issue: the gate verified that the file at
$Z3 reported "Z3 version 4.12.1" but did NOT
mechanically guarantee that the exact same Z3 was
the solver process used by Dafny. Dafny auto-
discovers Z3 from PATH and the distribution ships
BOTH z3-4.12.1 and z3-4.14.1 in z3/bin/, so a
PATH-resolved invocation could pick a different Z3.

Fix: pass --solver-path "$Z3" to dafny verify so
the checked executable is the exact solver Dafny
uses:

  $ grep 'solver-path' scripts/quality/formal-dafny.sh
  "$DAFNY" verify --solver-path "$Z3" \
    --warn-redundant-assumptions \
    --warn-contradictory-assumptions \
    "$DFY" >"$RV" 2>&1

Dafny 4.11.0 documents this flag:
  --solver-path <solver-path>
      Can be used to specify a custom SMT solver
      to use for verifying Dafny proofs.
