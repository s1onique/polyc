The only difference from the legacy baseline is the ORDER of two
interleaved groups. The legacy Bash harness emitted all four
'zero ptrtoint/inttoptr' rows, then all four
'zero getelementptr inbounds' rows. The PolyC harness emits
them per fixture (read0 ptrtoint, read0 inbounds, read2 ...).
This ordering was ALREADY the case before this ACT: the C1 RED
run (c1/gep01-red-run.txt) has exactly the same order. The
assertion SET is unchanged.
