### No runtime fallback in the production path

In `src/parser.c::CalcPadding`, the legacy C algorithm body exists ONLY
inside the `#else` branch of the `#ifdef HCC_USE_SELFHOST_PARSER_PADDING`
conditional. Production builds define the macro, so the `#else` branch is
not compiled into the production binary. The G0 binary is the only build
in which the legacy body is live, and it is a deliberate control.
