ACT=ACT-POLYC-SELFHOST-PARSER-PADDING01-CORRECTION04
PHASE=C1 (body label) / ACT-Phase trailer=EVIDENCE

This file captures the LIVE validator contract by empirical
fixture-test, not by guessing. The exact trailer placement for C0..C4
is derived here.

## Phase enum (literal, validator-enforced)

```
RED | IMPL | EVIDENCE | CLOSE
```

Custom labels like `C0`, `C1`, `AUTH`, `IMPL-RESTORE`, etc. are
rejected with `STATUS=FAIL: ACT-Phase 'XXX' not in {RED,IMPL,EVIDENCE,CLOSE}`.

## Verdict regex

`grep -Eq '^(PASS(_[A-Z0-9_]+)*|HALT_[A-Z0-9_]+)$'`

`PASS_PENDING_EXTERNAL_TERMINALITY` passes (one token, no spaces).
`HALT_FALSE_GREEN` passes as a corrected verdict.

## Cardinality (live-validator)

```
ACT:                     exactly 1 (RED/IMPL/EVIDENCE/CLOSE)
ACT-Phase:               exactly 1
ACT-Verdict:             exactly 0 on RED/IMPL/EVIDENCE
                         exactly 1 on CLOSE
ACT-Supersedes:          0 or 1, CLOSE-only (per range-checker)
ACT-Corrected-Verdict:   0 or 1, CLOSE-only, requires ACT-Supersedes,
                         value matches verdict regex
```

## CORRECTION04 mapping (body label -> trailer ACT-Phase)

The body label is for human reading; the trailer is the literal
validator enum:

```
C0 AUTH      -> ACT-Phase: RED
C1 RECON/RED -> ACT-Phase: EVIDENCE
C2 RESTORE   -> ACT-Phase: IMPL
C3 VERIFY    -> ACT-Phase: EVIDENCE
C4 CLOSE     -> ACT-Phase: CLOSE
```

This mapping matches the historical CORRECTION03 commit-message
trailer pattern (`8d87083` was `ACT-Phase: RED`, `1c5226d` was
`ACT-Phase: IMPL`, etc.). The C3 `EVIDENCE` phase also matches the
historical pattern (`c0845e2` was `ACT-Phase: EVIDENCE`).
