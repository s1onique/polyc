# C2 IMPL — implementation delta from C1 freeze to C2 close

## Source files

### tools/bootstrap/selfhost-lexer-scalar-literal.HC  (NEW)
PolyC translation of the frozen C region:
  - SC_IsNum / SC_IsHex / SC_IsNumTerminator — byte-class predicates
    (inlined as I64 functions; PolyC macros with `\` continuation crash
    stage0 hcc).
  - SC_PeekAt — bounded peek with 0 for out-of-range indices.
  - SC_CountNumberLen — verbatim translation of countNumberLen from
    src/lexer.c, including f32/f64 suffix recognition.
  - SC_LexCharConst — verbatim translation of lexCharConst body,
    INCLUDING the slot-counter semantic (each raw char counts 1; each
    escape sequence counts 1, regardless of span).
  - BootstrapScanScalarLiteral — public ABI 3 entry; dispatches to
    SC_LexCharConst on '\'' and to SC_CountNumberLen + libc strtoll /
    strtoul / strtod on digits/'.'. Sets *out_strlen on every path.

### tools/quality/lexer07-scalar-literal-oracle.c  (MODIFIED)
Added *out_strlen parameter to BootstrapScalarLiteralOracle signature;

### tools/quality/lexer07-direct-differential.c  (NEW)

## PolyC capability observations
- PolyC macros with `\` continuation crash the compiler; converted
  SC_IS_NUM/HEX/TERMINATOR to inline I64 functions.
- PolyC rejects `(void)expr` and `(U64)\0` casts; replaced with
  assignment-to-self and memcpy type punning via explicit
  memcpy(&bits, &v, 8).
- Hex `0x` with no digits: production behavior is I64=0 ishex=1, not
  error (strtoull accepts bare prefix). Fixtures corrected to match.
- `1e-2` is I64=1 (countNumberLen treats `-` as terminator; strtoll
  stops at `e`). Fixtures updated.
- F64 bits preserved via `memcpy(&bits, &v, 8)` rather than `*(U64*)&v`.

## Fixed-point iteration (SDF)
Multiple iterations of build + differential + analyze were required to
reach PASS, including:
  iter 1: brace placement (#else branch needed its own `}`).
  iter 2: lexCharConst cursor model (public function expects src[cursor]
          == '\''; wrapper passes src = l->ptr - 1 with cursor = 0).
  iter 3: lexCharConst l->ptr advance (saved_ptr + out_end, not l->ptr
          += out_end, because l->ptr was already past the leading
          quote after lexNextChar).
  iter 4: out_strlen ABI extension (production counts "slots" not bytes
          for char consts; out_strlen now carries this semantic through
          the wrapper into l->cur_strlen).
