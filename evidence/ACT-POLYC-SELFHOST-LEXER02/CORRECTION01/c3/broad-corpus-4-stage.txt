## 4-stage broad corpus conservation

### HolyC-lib canonical corpus (24 files, 5519 scalar tokens)

For each .HC file in src/holyc-lib:
  1. Run ./build/hcc        (stage0, ./hcc) with -tokens
  2. Run ./build/hcc-bootstrap02 (stage1) with -tokens
  3. Run ./build/hcc-bootstrap03 (stage2) with -tokens
  4. Run ./build/hcc-bootstrap04 (stage3) with -tokens
  5. Filter each output to TK_I64 | TK_F64 | TK_CHAR_CONST | TK_STR
  6. Sort each side, pairwise-diff (excluding BUILD_LABEL if any)
  7. For each file: pass iff all 6 pairwise stage diffs are empty

Result: 24/24 files MATCH across all 4 stages.
Total scalar tokens (stage0 sample): 5519.

### Wider .HC corpus (189 files, 14044 scalar tokens)

For each .HC file in src/ and tools/ EXCEPT tools/bootstrap/*:
  Same procedure as above.

Result: 189/189 files MATCH across all 4 stages.
Total scalar tokens (stage0 sample): 14044.

### Why exclude tools/bootstrap/*

The 4 .HC files under tools/bootstrap/ are the self-host
components (identifier_scanner, operator_punctuation_recognizer,
scalar_literal_scanner, plus one wrapper). Their lex output is
exercised via the direct-differential harness and the real-lexer
seam runner; running them as part of a broad corpus is
non-load-bearing because the corpus test runs the entire lexer
on those files. They are excluded from the broad corpus because
they reference PolyC intrinsics that may not parse cleanly under
all 4 stages.

### Why 24 src/holyc-lib files is the canonical corpus

The canonical corpus used by every prior LEXER and BOOTSTRAP ACT
in the lineage:
  - ACT-POLYC-BOOTSTRAP01: src/holyc-lib corpus (24 files)
  - ACT-POLYC-BOOTSTRAP02: src/holyc-lib corpus
  - ACT-POLYC-SELFHOST-LEXER01: src/holyc-lib corpus
  - ACT-POLYC-SELFHOST-LEXER01-CORRECTION01: src/holyc-lib corpus
  - ACT-POLYC-SELFHOST-LEXER-SURFACE-RECON01 lineage:
    src/holyc-lib corpus

The 24-file set is the canonical lexer/seam corpus across the
factory. CORRECTION01 also extends to all 189 lexable .HC files
for completeness; both pass with zero divergence.
