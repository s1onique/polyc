# Error corpus conservation: edge cases (EOF, malformed, etc.) produce
# the SAME lex output under stage0 and stage1.

  (28 cases total):

    T02_plus           "42+1;"
    T03_eof            "42"           (no terminator)
    F05_exp            "1e2;"

    N01..N08           xx-prefix sequences

    H01..H03           hex integers

  Only the BUILD_LABEL header differs. All 28 cases produce
  IDENTICAL output, including all 8 edge cases (T01..T03, F05,

## Conclusion
  No regression in error/edge behavior. The wrapper's error
  semantics (out_error=2 unterminated, out_error=3 overflow,
  out_error=0 normal) are preserved across the production
  dispatcher and the PolyC component.
