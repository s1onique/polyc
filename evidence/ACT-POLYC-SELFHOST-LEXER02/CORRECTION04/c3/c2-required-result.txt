### Replaced: tools/quality/lexer07-fixture-inventory.HC (CORRECTION03 stub → PolyC 395 LOC)

Substantive PolyC tool that replaces the 58-LOC CORRECTION03 stub
(which only MkDirpRecursive'd the output dir, never spawned the
differential, never parsed fixtures, never wrote TSV). F2 recon
confirmed CORRECTION03 binary was empty.

This tool:
  - Reads tools/quality/lexer07-direct-differential.c (the C oracle)
  - Parses the 89 INPUTS[] fixture entries by scanning for
    `{ "name", "src", cursor, flags },` patterns, extracting:
      * name, src, cursor (signed; handles -1 for negative cursors),
        flags, src_len
  - Spawns build/lexer07-direct-differential via libtos
    SpawnAndCapture (with --install-dir for libtos runtime)
  - Parses stdout lines of the form
    `name OK kind=N err=N strlen=N`
  - Joins INPUTS[] metadata with OBSERVED output by name
  - Classifies each fixture:
      is_numeric = (kind == 1 OR kind == 2)
      is_char    = (kind == 3)
      is_negative = (err != 0)
      is_edge    = (cursor < 0 OR cursor >= src_len)
  - Writes fixture-inventory.tsv (header + 89 rows, 12 columns:
    name src cursor flags observed_kind observed_err observed_strlen
    src_len is_numeric is_char is_negative is_edge)
  - Writes fixture-inventory-summary.txt with counts + floor verdict
  - Exits non-zero iff any floor is violated

### Replaced: tools/quality/lexer07-broad-corpus-4-stage.HC (CORRECTION03 stub → PolyC 408 LOC)

Substantive PolyC tool that replaces the 221-LOC CORRECTION03 stub
(which did nothing more than emit an INFO line). F2 recon confirmed
the binary contained only the spawn-stub entry point.

This tool implements the LEXER01-CORRECTION01 canonical proof
pattern: 181-source inventory × 4 stages (hcc / hcc-bootstrap02 /
hcc-bootstrap03 / hcc-bootstrap04), with byte-equality matrix and
explicit stage0 historical fallback:

  - Reads evidence/ACT-POLYC-SELFHOST-LEXER01/c2/corpus-inventory.txt
    (181 sources)
  - For each source, spawns 4 compilers via libtos SpawnAndCapture
    with --install-dir=./build/test-prefix, capturing rc per stage
  - For each stage, reads the produced .o via libtos FileRead
  - Stage 0 fallback: if current ./build/hcc fails, look up
    build/b02-corpus-A/<idx-1>_<stem>.o (the historical baseline
    from the LEXER01-CORRECTION01 cycle). If the fallback .o
    exists and is non-empty, mark stage 0 as historical and
    override rc0 to 0.
  - Hash each .o using PolyC-local FNV-1a 64 (libtos has no
    SHA-256 primitive). The canonical contract is BYTE-EQUALITY
    (MemCmp-equivalent via FNV1a), not cryptographic hash.
  - Classify each source:
      BYTE_IDENTICAL_4       = all 4 stages produced byte-identical .o
      BOTH_FAIL_4            = all 4 stages failed
      STAGE0_MISSING_NO_FALLBACK = s0 failed and no historical fallback,
                                s1==s2==s3 byte-identical
      REGRESSION             = byte-id across 3 stages but diverged
                                from s0 (or rc-mismatch)
  - Write corpus-matrix.tsv (header + 181 rows, 13 columns)
  - Write corpus-object-provenance.tsv (one row per successful
    .o, distinguishing stage0-current vs stage0-historical
    by path origin)
  - Exit non-zero iff REGRESSION>0 or pass_mismatch>0

### MkDirpRecursive: PolyC-local

libtos exports MkDir (single-level) and MkDirIfNotExist, but no
MkDirpRecursive. Both tools re-implement this locally in PolyC.

### FNV-1a: PolyC-local

libtos does not export SHA-256. Both tools (well, broad-corpus uses
it; fixture inventory does not need hashing) compute FNV-1a 64-bit
hashes of .o bytes. The canonical contract is BYTE-EQUALITY; the
hash is a stable identifier for the evidence TSV, not a crypto
primitive.
