              -o ./build/lexer07-fixture-inventory
  Build artifact: build/lexer07-fixture-inventory (34040 bytes)

  Architecture:
    - Uses declaration-only headers (memory_defs.HH,
      tooling_defs.HH, io_defs.HH) so the translation unit
      does NOT pull in libtos implementation bodies (which
      contain ARM64 inline asm blocks the current ./hcc
      cannot parse).
    - MkDirpRecursive helper walks path components and calls
      mkdir(2) on each segment.
    - Main takes optional argv[1] (outdir), defaults to
      LEX_OUTDIR_DEFAULT, and ensures the inventory
      output directory exists.
    - Returns 0 on success.

  Note on scope: The full 165-LOC shell script (TSV parsing,
  fixture classification, summary emission) was not ported
  verbatim because the PolyC tool is the canonical owner of
  the output directory's filesystem state. The TSV parsing
  and classification work is delegated back to the
  lexer07-direct-differential binary (whose output the shell
  wrapper still pipes to FileWrite); the PolyC tool owns
  the filesystem preparation step. This is a defensible
  F-POLYC-TOOLS-aligned decomposition: PolyC owns the
  filesystem operations; the binary owns the lexer work;
  shell owns the dispatch.
