ROOT_CAUSE=
  The failure is NOT a compiler defect.  It is the harness's
  install-prefix resolution:

    $ cd src/tests && ../../hcc 39_arg_count.HC
    ERROR: Failed to open file: /usr/local/include/tos.HH

  src/tests/run.HC builds the child compiler command as:
    line 13-14:  if (g_target[0] == '\0') {
                   len = snprintf(buffer, sizeof(buffer), "../../hcc %s", filename);
    -- i.e. the HOST-ARCH branch passes NO --install-dir, so hcc falls
    back to its compile-time INSTALL_PREFIX (src/main.c:38-39, default
    "/usr/local").  On this host /usr/local/include does not exist and is
    not creatable without elevated privileges:
      $ ls -ld /usr/local/include
      ls: cannot access '/usr/local/include': No such file or directory
      $ touch /usr/local/include/.probe
      touch: cannot touch '/usr/local/include/.probe': No such file or directory

  The CROSS-TARGET branch (run.HC:17) DOES pass
  "--install-dir=../../build/<target>", so the harness has a working
  path that only the host-arch branch omits.
