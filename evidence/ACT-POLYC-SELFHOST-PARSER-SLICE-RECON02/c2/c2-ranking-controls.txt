# The ACT requires nine mandatory anti-bias controls (SECT_8.3) and
# forbids any control from "passing purely because an expected result
# was hardcoded in a report".  Every control below is EXECUTED against the
# mechanical ranker; the outputs are the ranker's actual stdout.
#
# The ranker (build/slice-recon02-rank/rank.sh) is a disposable diagnostic
# in the IGNORED build directory.  It is NOT a tracked tool (F-POLYC-TOOLS
# is not violated: no new substantive shell or C tool is added to the
# repository).
#
# RANKER SELF-CHECK (prerequisite for trusting any control below):
#   Feeding the ranker the RECON01 historical input reproduces the
#   RECON01 historical WINNER (CAND-002):
#     $ build/slice-recon02-rank/rank.sh build/slice-recon02-rank/recon01-input.tsv
#     1  CAND-002  0 1 2 0 0 0  src/parser.c:430  YES
#     2  CAND-001  0 1 2 0 0 1  src/parser.c:791  YES
#     ...
#   RANKER_REPRODUCES_RECON01_WINNER=YES
#
#   NOTE (residue, P1, NOT a blocker): the ranker places CAND-004
#   (src/parser.c:397) at rank 3 and CAND-003 (src/parser.c:410) at
#   rank 4, whereas RECON01's published tables place CAND-003 at rank 3
#   and CAND-004 at rank 4.  RECON01's own C3 note
#   (c3-ranking-recompute.tsv, NOTES_ON_R6_TIE_BREAK) states "CAND-004
#   wins on R6 (line_start smaller)", which agrees with the ranker and
#   disagrees with RECON01's published order.  The published RECON01 order
#   is preserved as history under F14; it is not rewritten here.
#   IMMATERIALITY: the disagreement does not change the RECON01 winner
#   (CAND-002 in both) and it does not change the C2 winner here,
#   because CAND-003 is EXCLUDED by the eligibility conjunction (R0=4)
#   and CAND-004 is EXCLUDED on production_delegation_feasible.
