the REAL legacy parseGetPriority body is the one that executes.  The
Makefile rule ASSERTS this and fails the build if it ever does not
hold:

    echo "slice03-prslib-legacy.o: the object references the PolyC component;
           the delegation flag is NOT off" >&2; exit 1; fi
