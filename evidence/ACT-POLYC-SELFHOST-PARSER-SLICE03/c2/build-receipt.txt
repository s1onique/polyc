THE LEGACY ORACLE OBJECT
=======================

COMMAND=make build/slice03-prslib-legacy.o
OUTPUT:
  SLICE03_LEGACY_ORACLE=./build/slice03-prslib-legacy.o (delegation OFF: the real legacy body is executed)

COMMAND=nm build/slice03-prslib-legacy.o | grep -i "OperatorPrecedenceOracle\|parseGetPriority\|BootstrapOperatorPrecedence"
OUTPUT:
  00000000000021f0 T _ParserLegacyOperatorPrecedenceOracle
  0000000000002220 t _parseGetPriority

The oracle object carries NO _BootstrapOperatorPrecedence symbol:
the delegation is OFF in that build, so the REAL legacy
parseGetPriority body is the one that executes.  The Makefile
rule ASSERTS this:

  @if nm $@ | grep -q _BootstrapOperatorPrecedence; then ... exit 1; fi
