--- ISOLATED ROOT CAUSE ---
The compiler inline-asm parser (src/asm/asm.c) rejects the "local label"
syntax "@@N". Isolated by bisecting the asm construct:

  $ printf "I32 Main(I32 argc, U8 **argv)
{
  asm {
    LDP    X29, X30, [SP], 16   // restore FP/LR
    RET
  }
}
" > t.HC
  $ ./hcc -c t.HC            -> COMPILES (no error)

  $ printf "... asm {
    CBZ    X0, @@1
    SUB    X0, X0, 8
@@1:
    RET
  }
}
" > t.HC
  $ ./hcc -c t.HC            -> ERROR: asm: unexpected token at start of line

CONCLUSION: "@@N" local labels are unsupported by src/asm/asm.c.
src/holyc-lib/memory.HC uses @@1/@@2 labels in its aarch64 asm block,
so ANY .HC file that includes src/holyc-lib/memory.HC (directly or via
strings.HC / tooling.HC) cannot be compiled on this host today.
