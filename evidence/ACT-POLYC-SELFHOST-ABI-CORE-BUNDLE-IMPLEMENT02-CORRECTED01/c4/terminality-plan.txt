THE KNOWN DEVIATIONS THE RECEIPT MUST RECORD HONESTLY
--------------------------------------------------------------------------
These are NOT hidden by the receipt. The receipt records them verbatim.

DEVIATION-01  THE COMMIT-PHASE SHAPE
  The ACT's section 6 states the expected successful range as
  "C0 RED -> C1 EVIDENCE -> C2 IMPL -> C3 EVIDENCE -> C4 CLOSE (five
  commits)". The ACT's ACTUAL committed range is RED, IMPL, EVIDENCE,
  CLOSE: the C1 EVIDENCE phase's evidence files were committed
  together with the C3 EVIDENCE phase's files in the C3 commit, so the
  C1 phase has NO commit of its own.
  WHY IT WAS NOT REPAIRED: the repository's authoritative history is
  append-only from baf5dbd77cf89330699685dffd932c54031c815c, and a
  commit that already exists is immutable evidence. Inserting a C1
  commit BEFORE the C2 IMPL commit would require rewriting history,
  which the append-only invariant and the pre-push hook forbid.
  WHY IT IS NOT A HALT: the canonical Factory-v2 range checker, which
  the ACT names as its authority, has NO numeric commit-count rule and
  enforces only that the range be contiguous, that every commit carry
  the ACT id with a valid phase, that FIRST be RED, that exactly one
  CLOSE exist and be last, and that no commit after CLOSE carry the
  id. The ACT's committed range satisfies every one of those rules,
  and every commit's ACT-Phase trailer honestly classifies what that
  commit actually contains: the C3 commit contains evidence and is
  classified EVIDENCE.
  WHAT THE RECEIPT MUST DO: record the ACTUAL phase sequence, the
  ACTUAL commit count, and this deviation. It must NOT report five
  commits, because five commits were not made.

DEVIATION-02  THE PREDECESSOR'S F14 FREEZE HAS ONE ACCOUNTED DELTA
  The predecessor's 523-path freeze records
  docs/factory/act-handoff-map.tsv at its C3 digest, and the
  predecessor's OWN C4 added exactly one handoff-map row to that file.
  The delta is one insertion and zero deletions, introduced by the
  entry commit 23546c7c, and this ACT never touched that path. The
  strict result is 522 of 523; the authorised-exception result is
  522 of 523 plus this ACT's own ONE authorised append, which is
  recorded separately and is NOT folded into the strict figure.

DEVIATION-03  THE HISTORICAL NON-GREEN BASELINES
  F-NO-PYTHON is FAIL at the SAME 12 paths with zero new violations.
  F-POLYC-TOOLS is UNAVAILABLE because the canonical checker does not
  exist. The cross-target baseline is NOT_REMEASURED with its
  historical FAIL_ENVIRONMENT_PREFIX identity preserved. None of these
  is relabelled as a PASS.

DEVIATION-04  THE COMPARATOR'S ONE INTENTIONAL NARROWING
  The corrected ABI normalises is_float to {0,1} while the legacy C
  table tested its truthiness. The G0 oracle therefore rejects an
  is_float outside {0,1} with NULL, so that the G0 stream and the
  G1..G3 streams are compared over the SAME admissible domain. The
  narrowing is the corrected contract's, and the fixture contract's
  OUT_OF_DOMAIN_IS_FLOAT partition expects (null) accordingly.

THE RECEIPT'S SHAPE
--------------------------------------------------------------------------
The receipt is a plain-text file OUTSIDE the Git tree. It states the
ACT id, the terminal HEAD and TREE it is bound to, the date and the
auditor, and then one line per check with the command, the exit code
and the observed output. It ends with an explicit statement of which
acceptance criteria it discharges.

It is NEVER committed. No ordinary compensating commit is made after
the CLOSE. The receipt is not backdated and it does not claim the
SHA of a commit that contains it.
