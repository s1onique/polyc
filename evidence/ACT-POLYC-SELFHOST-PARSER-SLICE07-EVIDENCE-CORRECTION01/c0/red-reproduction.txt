# RED-2a  THE C-ON PRODUCTION PATH DOES NOT CONTAIN THE C DECISION.
#
# The selected C decision is compiled OUT of the production path by the
# dedicated selector.  Measured at C0 from the live production object:
#
# COMMAND=nm build/CMakeFiles/hcc.dir/parser.c.o | grep -q ' U _BootstrapCompoundBlockAppendsStatement' && echo IMPORTS

# The production parser object IMPORTS the PolyC symbol as an undefined
# reference.  The legacy C branch is behind
# `#ifdef HCC_USE_SELFHOST_PARSER_COMPOUND_BLOCK_APPEND` / `#else`, so

# PolyC source therefore CANNOT be a mutation of the selected C
# decision; and conversely, a mutation of the selected C decision CANNOT
# affect the C-ON production path at all.  The two subjects are
# DISJOINT.  That disjointness is the mechanical reason the
# PolyC-source experiment is not a C-decision experiment.
#
# COMMAND=grep -n 'HCC_USE_SELFHOST_PARSER_COMPOUND_BLOCK_APPEND' src/parser.c
#   1978:#ifdef HCC_USE_SELFHOST_PARSER_COMPOUND_BLOCK_APPEND
