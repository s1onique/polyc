=== THE LEGACY C DECISION, LIVE, IN THE REAL C-OFF OBJECT ===

COMMAND=otool -tvV build/corr01-c-off/CMakeFiles/hcc.dir/parser.c.o \
          | awk '/_ParserLegacyCompoundBlockAppendsOracle:/{f=1} f{print}'

_ParserLegacyCompoundBlockAppendsOracle:
0000000000003734	cmp	w0, #0x107       ; 0x107 == 263 == AST_DECL
0000000000003738	mov	w8, #0x100       ; 0x100 == 256 == AST_GVAR
000000000000373c	ccmp	w1, w8, #0x0, eq ; the SHORT-CIRCUITED declvar_kind test
0000000000003740	cset	w0, ne           ; 0 (SKIP) iff both matched, else 1 (APPEND)
0000000000003744	ret

THIS IS THE SELECTED C DECISION, COMPILED INTO THE REAL PRODUCTION
PARSER OBJECT OF THE REAL C-OFF COMPILER:

  - the AST_DECL constant 263 (0x107) is compared against stmt_kind;
  - the AST_GVAR constant 256 (0x100) is compared against declvar_kind;
  - the COMPARISON IS SHORT-CIRCUITED (ccmp ... eq), so declvar_kind is
    consulted ONLY when stmt_kind is already AST_DECL;
  - the result is the frozen boolean: 0 == SKIP, non-zero == APPEND.

This is the DECISION that the N-06 mutation must attack, and it is
ACTIVE, not dormant: it is in the object that the production
executable links.
