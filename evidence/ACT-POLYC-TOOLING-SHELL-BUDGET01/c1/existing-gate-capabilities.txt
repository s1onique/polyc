C1 RED -- existing shell-loc-gate capability matrix
=====================================================

scripts/quality/shell-loc-gate.sh (26 LOC) does the following:

  (a) Reads baseline.txt (path<TAB>loc) generated by
      SHELL-INVENTORY01 C2.
  (b) Walks scripts/quality/ for *.sh files (maxdepth 1).
  (c) For each present file:
      - if no baseline entry exists, it must be <=50 LOC
        (otherwise FAIL NEW).
      - else, current loc must be <= baseline.loc
        (otherwise FAIL GROW).
  (d) Exit 0 on PASS, exit 1 on any FAIL.

Capability matrix vs ACT §8 REDs:

  B1 grandfathered file exceeds budget          PARTIAL
      shell-loc-gate.sh does check growth vs baseline,
      but only for scripts/quality/ (maxdepth 1). It
      does NOT cover scripts/ root, scripts/install-git-hooks.sh,
      evidence/, src/asm/, packaging/. Growth in those
      paths slips past.

  B2 budget increased                            ABSENT
      shell-loc-gate.sh has no monotonicity check. It
      never compares current baseline vs previous
      baseline; the baseline.txt is consumed verbatim.

  B3 migrated file reappears                     ABSENT
      shell-loc-gate.sh has no manifest of MIGRATED
      paths. If scripts/quality/llvm-gep01-test.sh
      is recreated, it is classified NEW and either
      accepted (if small) or rejected (if large). The
      zero-budget invariant is unenforced.

  B4 new substantive shell file                  PRESENT
      New *.sh under scripts/quality/ >50 LOC is rejected.

  B5 current LOC below budget                    PRESENT (PASS only)

  B6 tiny wrapper                                PRESENT
  B7 tiny wrapper grows >50                      PRESENT

  B8 untracked budget row                        ABSENT
      shell-loc-gate.sh has no per-file budget manifest.

  B9 unbudgeted tracked shell file               ABSENT
      shell-loc-gate.sh scopes itself to scripts/quality/
      and rejects any path outside baseline.txt only as NEW.
      It does not require every tracked .sh to appear in a
      canonical budget.

DOMAIN SCOPE DEFECT (mechanical, F13 evidence):
  shell-loc-gate.sh uses `find "$ROOT" -maxdepth 1` with
  ROOT=scripts/quality. This is partial coverage.

  Demonstration:
    $ ls scripts/quality/*.sh | wc -l
    24
    $ git ls-files '*.sh' | wc -l
    42

  18 of 42 tracked shell files are outside its discovery walk
  (the entire evidence/ subtree, packaging/install.sh, src/asm/test_jit_ir.sh,
   scripts/install-git-hooks.sh, scripts/quality/llvm-spike-test.sh's
   under-tree -- none of these grow past baseline and remain
   undetected).

OBSERVATION:
  The existing gate is a useful but incomplete ratchet.
  SHELL-BUDGET01 must add a separate, complete-coverage,
  monotonic-budget verifier (the new shell-budget-gate.sh)
  that runs in parallel with shell-loc-gate.sh and is
  itself <=50 LOC.
