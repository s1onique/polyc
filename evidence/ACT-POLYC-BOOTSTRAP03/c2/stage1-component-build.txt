------------------------------------------------------------
Provenance anchor
------------------------------------------------------------

The producer (`./build/hcc-bootstrap02`) IS STAGE1 — it
contains `_BootstrapScanIdent` because it links the
stage0-produced B1 object. Stage1 therefore both:

1. CARRIES the B1 component (already true at C1).
2. EMITS a freshly compiled B1 object for stage2.

The sha256 (a1b620c0...) is identical to stage0's output
because both stages use the same host-clang backend. This
is incidental — the binding proof is the **producer
identity**, not the byte identity. The build graph
records stage1 as the producer.
