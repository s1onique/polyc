Binding equalities (ACT §17)
------------------------------------------------------------

```text
STAGE1_B1_OUTPUT_PATH     = /Volumes/.../build/bootstrap03-ident.stage1.o
STAGE2_B1_LINK_INPUT_PATH = /Volumes/.../build/bootstrap03-ident.stage1.o
STAGE1_B1_OUTPUT_PATH     == STAGE2_B1_LINK_INPUT_PATH     YES (path equality)

STAGE1_B1_OUTPUT_SHA      = a1b620c076e81d898f953889f2b9db97f0bf8f6228af3b4a10644e2e78cd854f
STAGE2_B1_LINK_INPUT_SHA  = a1b620c076e81d898f953889f2b9db97f0bf8f6228af3b4a10644e2e78cd854f
STAGE1_B1_OUTPUT_SHA      == STAGE2_B1_LINK_INPUT_SHA      YES (hash equality)

STAGE2_B1_LINK_COMMAND    = target_link_libraries(hcc-bootstrap03
                              ${BOOTSTRAP03_IDENT_OBJECT} m)
                              with BOOTSTRAP03_IDENT_OBJECT = the stage1-produced object
STAGE2_B1_ARTIFACT_PROVENANCE = STAGE1 (binding by build graph)
```

Path equality is the strongest proof (same file on disk
is consumed). Hash equality is the corollary (same
content). Both equalities hold.
