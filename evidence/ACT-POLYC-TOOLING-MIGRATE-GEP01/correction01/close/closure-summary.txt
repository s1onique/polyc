ROOT CAUSE
----------
The c1 PolyC harness predicates were strictly weaker than
the frozen legacy Bash oracle on six rows:

  - rows 04 / 07 used whole-file
    Contains("getelementptr i8, ptr %") which accepts
    constant-index IR (the regex needs both operands to be
    numbered %[0-9]+ with ", i64 %" infix);
  - row 08 was weakened to
    Contains("load i8, ptr %") which accepts an arbitrary
    byte load instead of the legacy SSA-name-binding
    "load i8, ptr %gep_i8";
  - rows 26 / 27 / 28 used whole-file
    Contains(opcode) && Contains(marker) which accepts
    opcode/marker on separate lines.

The P1 scratch rule was also broken: the harness did NOT
own a per-run child dir, which caused a 2/12 noisy FAIL
cascade when --scratch did not pre-exist.
