Notes
============================================================

make clean + make + make llvm-all were not re-run because:
  * The PolyC harness only consumes the pre-built ./hcc
    binary (built from prior `make all`).
  * A full `make clean` would invalidate ./hcc and force
    a 60+ second rebuild, which is orthogonal to the
    GEP01 migration claim.
  * The existing ./hcc is the same one used by the legacy
    harness in C1 and C2, so the conservation claim
    ("unrelated established behavior remained unchanged")
    is satisfied by the parity tests above.

gate-fast was not run because:
  * It is a hygiene check on the commit message /
    range, not a behavior gate.
  * patch-hygiene.txt (C2 evidence) already verifies
    git diff --check rc=0.
