THE PARSER SUITE CONSERVATION
=============================

THE BASELINE IS THE ENTRY TREE, NOT A HISTORICAL CLAIM
-------------------------------------------------------
The conservation baseline is the ACT's ENTRY HEAD, not a predecessor's
claimed result.  Both numbers below were MEASURED, on the entry tree
and on the C3 tree, in the SAME way.

THE TWO COMPILERS
------------------
  ENTRY = /tmp/slice06-baseline/hcc
         built from a detached git worktree at the entry commit
         1ccf28d58fec9c856c12ad1f71bab9a2ca6e18e0
  C3    = /tmp/slice06-c3/hcc
         built from a detached git worktree at the C2 commit
         a5591d6be4fe037a3ac15a9c1d313d26d5ff581a

  Both were configured with -DCMAKE_INSTALL_PREFIX=<their own prefix>,
  so the compile-time INSTALL_PREFIX matches the runtime prefix.
  Without that, this host has no /usr/local and every test fails with
  "Failed to open file: /usr/local/include/tos.HH" -- an ENVIRONMENT
  condition, not a parser result.
