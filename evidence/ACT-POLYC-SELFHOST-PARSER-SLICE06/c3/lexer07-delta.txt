A NOTE ON THE INVOCATION
------------------------
The corpus tool takes the corpus inventory and an output directory as
arguments.  Invoked WITHOUT them it uses a default mode that measures
something else; that mode was observed once during this phase and
discarded because it does not measure the frozen corpus.  The
measurements above are from the CORRECT invocation, which is the same
one the predecessor used.
