# --- Negative-control contract for the C2 repair --------------------------

# The C2 verifier SHALL run this exact procedure against fresh-built
# G0..G3 (rebuilt under distinct compilers with distinct fresh_build_records).

NEGATIVE_CONTROL_PROCEDURE_BEGIN
1. independently build pristine G1 and G3;
2. preserve G3's expected provenance row;
3. replace ONLY the temporary G3 output bytes with G1's bytes;
4. attach G1's provenance record to the substituted artifact
   (so its output_sha256 matches expected_G3.output_sha256);
5. run the C2 provenance verifier;
6. require rejection because the generation/build identity does not
   match expected G3;
7. restore independently-built G3;
8. require PASS.
