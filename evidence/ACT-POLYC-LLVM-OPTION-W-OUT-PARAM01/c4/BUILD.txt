ACT-POLYC-LLVM-OPTION-W-OUT-PARAM01 C4 IMPL-B BUILD PROCEDURE
============================================================
Date prepared: 2026-09-12

This file describes the exact commands used to build the C4
IMPL commit and capture the witness outputs. All commands
were run from the repository root.

PREREQUISITES
=============
* LLVM 22 toolchain (`llvm-as`, `opt`, `llvm-config` in
  $PATH)
* CMake / Make build environment

BUILD
=====
$ make llvm-all

The build produces the `hcc` binary at the repository root.
The four modified C-source files (src/llvm-backend.c,
src/llvm-backend.h, src/llvm-backend-cap.c) compile cleanly
with the standard -Wunused-* warning set; no errors.

REPRODUCTION (per fixture)
==========================
For each witness fixture F in {c4_phi_only,
c4_phi_short_circuit_or, c4_phi_short_circuit_and,
c4_phi_multi_pred, c4_p5_safe_fwd_single_pred,
c4_p6_multidef_local}:

$ /Volumes/UserData/Users/chistyakov/Projects/SPbNIX/polyc/hcc \
    --emit-llvm \
    --install-dir=/tmp/polyc-c4 \
    -o /tmp/F.ll \
    evidence/ACT-POLYC-LLVM-OPTION-W-OUT-PARAM01/c4/witness-fixtures/F.HC
$ llvm-as /tmp/F.ll -o /tmp/F.bc
$ opt --passes=verify /tmp/F.bc -S -o /tmp/F-opt.ll

Expected per-fixture results:
* hcc exit code: 0
* llvm-as exit code: 0
* opt --passes=verify exit code: 0
* CAPABILITY_COUNTERS line on stderr with shape_dependent
  counter incrementing by exactly N where N is the number
  of IR_PHI instructions in the function.

For the multi_pred fixture (3 PHIs):
  CAPABILITY_COUNTERS supported=12 rejected=0 shape_dependent=4 ...

For the short-circuit fixtures (1 PHI):
  CAPABILITY_COUNTERS supported=7  rejected=0 shape_dependent=2 ...

For the Option-W regression fixtures (0 PHIs):
  CAPABILITY_COUNTERS supported=1  rejected=0 shape_dependent=0 ...   # p5
  CAPABILITY_COUNTERS supported=11 rejected=0 shape_dependent=6 ...   # p6

(The per-fixture supported/shape_dependent numbers are the
delta from the prior baseline; the absolute counter depends
on the Option-W shape of the specific fixture.)
